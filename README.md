# ごうのすけのゲーム

スマホのブラウザで動く、オリジナルキャラのタワーディフェンスゲーム。

**遊ぶ → https://akihikoito-apps.github.io/gounosuke-game/**

## あそびかた

上のURLを開くだけです。**横向き（よこ持ち）推奨**。

パソコンで確認するときは `index.html` をダブルクリックでも動きます（サーバー不要）。

### iPad / iPhone のホーム画面に入れる

1. **Safari** で上のURLを開く
2. 右上の**共有ボタン**（□に↑）をタップ
3. **「ホーム画面に追加」** → 「追加」

アイコンから起動すると全画面のアプリになり、**一度開いたあとはネットがなくても遊べます**。

## ずかん

トップ画面の **「ずかん 📖」** から開けます。

- **みかた / てき** をタブで切りかえ
- **属性**（10種類）と **レア度**（味方のみ）でしぼりこみ
- 1体ずつ **絵・基本ステータス・属性・レア度・特性の説明** が出ます
- ステータスは **★5つの目安と数字の両方**で出ます

```
たいりょく        ★★★☆☆  1900
こうげき          ★★★★☆  500
1びょうの ダメージ ★★★★☆  182
しゃてい          ★★☆☆☆  118
うごく はやさ      ★★☆☆☆  24
こうげきの はやさ  ★★★☆☆  2.8びょうに 1かい
だしやすさ        ★☆☆☆☆  コスト 1350
```

★の数は `STAR_SCALE`（`js/data.js`）で決まります。境目の数字を書きかえれば
図鑑の★も変わります。「こうげきの はやさ」と「だしやすさ」は
**小さい数字ほど★が多い**ように、境目を大きい順に書いています。

```js
const STAR_SCALE = {
  hp:    [600, 1500, 3000, 6000],   // 600未満=★1、1500未満=★2 …
  cycle: [3.6, 2.8,  2.0,  1.4],    // 小さいほど良いので大きい順
};
```

**出てきたキャラだけ**が載ります。味方は「持っているキャラ」、敵は
「戦闘で一度でも出会った敵」（`slot.seenEnemies` に記録）です。

戦闘中の **「メニュー」→「キャラ じょうほう」** からも開けます。
そのときは**そのステージに出る味方と敵だけ**にしぼられ、「もどる」で戦闘に復帰します。

特性の文章は `abilityLines()` が数値から自動で作るので、
`js/data.js` の数字を変えれば図鑑の説明も自動で変わります。

### 操作
| やること | どうする |
|---|---|
| セーブデータ | 起動時に3つから選ぶ（× ボタンで削除） |
| ずかんを見る | トップの「ずかん」／戦闘中は「メニュー」→「キャラ じょうほう」 |
| キャラを出す | 画面下のキャラアイコンをタップ |
| おかねを強くする | 左下の「おさいふ君」をタップ |
| 必殺技 | 右下の「ちゅどーん」（チャージが満タンのとき光ります） |
| はやさを変える | 右上の「倍速」ボタン（1.0 → 1.5 → 2.0 → 1.0…） |
| メニュー | 上の「メニュー」→「キャラ じょうほう」「せんとうを やめる」「せんとうに もどる」 |

戦場は**全体が常に1画面に収まる**ので、スクロール操作は要りません。

パソコンで遊ぶときは `1`〜`5` キーでキャラ、`W` でおさいふ君、`スペース` でちゅどーん、`F` で倍速切りかえ。

## ★ 数値をいじりたいとき → `js/data.js` だけ ★

`js/data.js` を開いて数字を書きかえ、保存してブラウザを**リロード**すれば即反映されます。
他のファイルは触らなくて大丈夫です。

### どこに何があるか

| 行のあたり | 中身 | よくいじるところ |
|---|---|---|
| `CONFIG` | 全体のルール | 属性倍率、初期資金、おさいふ君、ちゅどーん、自城HP、**戦場の広さと見えかた** |
| `UNITS` | 味方12体のステータス | コスト・体力・攻撃力・射程・速さ |
| `PARTY` | 画面下に並ぶ順番 | 並べかえ・出撃メンバー変更（最大10体） |
| `ENEMIES` | 敵62体のステータス | 同上 |
| `STAGES` | コース構成（第1〜6章 各7＝42コース） | 敵城HP、敵の出方、背景、報酬、敵の強さ倍率 |
| `TOWER` | あき坊の塔 | 特設ステージ（10階・実装ずみ） |
| `CHAPTERS` | 章の名前と地図の位置 | 名前・アイコン・地図上のx/y |
| `BACKGROUNDS` | 背景の色 | 空・山・地面の色 |
| `LEVEL` | レベルアップ | 必要けいけんち、1レベルの伸び |
| `GACHA` | ガチャ | 必要コイン、上限解放の最大値 |
| `RARITY` | レアリティ | 出現確率 |

### 用語のよみかた（`UNITS` / `ENEMIES` 共通）

| 名前 | 意味 | 大きくすると |
|---|---|---|
| `cost` | 召喚に必要なお金 | 出しにくくなる |
| `recharge` | 次に出せるまでの秒数 | 連打できなくなる |
| `hp` | 体力 | 死ににくくなる |
| `atk` | 攻撃力（1回ぶん） | 強くなる |
| `range` | 射程 | 遠くから一方的に殴れる（**いちばん効く**） |
| `speed` | 移動速度（1秒に進む距離） | 前線に早く着く |
| `attackInterval` | 攻撃の間隔（秒） | 攻撃が遅くなる |
| `attackWindup` | 振りかぶってから当たるまで（秒） | 出が遅くなる |
| `kbCount` | 何回ふきとばされるか | ねばり強くなる |
| `areaRadius` | 範囲攻撃の広さ | まとめて当たる |

> **コツ**：強さをいじるなら、まず `range`（射程）を触るのがいちばん体感が変わります。
> 次が `atk` と `attackInterval`。`hp` は最後でOK。

### よくある調整のレシピ

**「かんたんにして」**
```js
playerCastleHp: 4500,   →  8000     // 自分の城をタフに
startMoney: 250,        →  800      // 最初からお金持ち
```
```js
// STAGES の castleHp を減らす（敵の城が早く落ちる）
castleHp: 4300,  →  2500
```

**「画面の見えかたを変えたい」** — `CONFIG` で調整できます
```js
fieldLength: 1050,   // 戦場の長さ。小さくすると接近戦になり、キャラが大きく映る
charScale:   1.5,    // ふつうのキャラの大きさ
bossScale:   1.0,    // ボスだけの大きさ（別あつかい）
groundLine:  0.62,   // 地面の高さ。大きくすると下の余白が減り、キャラの上に余裕ができる
```
戦場の幅は `fieldLength` だけ見ればOKです。**画面の拡大率は自動計算**されるので、
`fieldLength` をいくつにしても横スクロールは発生しません（`castleMargin` と `viewWidth` は
自動調整用なので触らなくて大丈夫です）。

**「むずかしくして」**
```js
// ENEMIES の hp / atk を上げる、または STAGES の repeat を短くする
{ at: 50, id: 'togehaya', count: 2, gap: 2.5, repeat: 22 },  → repeat: 12
```

**「ひー坊をもっと強く」**
```js
hiibou: { ... atk: 430  →  600,  areaRadius: 46  →  70 }
```

**「新しい敵の出しかたを変える」** — `STAGES` の `waves` に1行足すだけ
```js
{ at: 70, id: 'honota', count: 5, gap: 0.3 },   // 70秒後に ほのた5体を0.3秒おきに
```

## ★ なんいどの はかりかた（作業する人むけ・大事）★

ここを間違えると、簡単すぎたり理不尽になったりします。
**過去に何度も同じ失敗をしているので、調整する前に必ず読んでください。**

### 1. 「勝てるか」ではなく「勝つまでの時間」で測る

このゲームは**安い壁を出し続ければ、ほとんど負けません**。
なので「勝てた／負けた」で測ると、ほぼ全部「勝てる」になって差が出ません。

| 勝つまでの時間 | 判定 |
|---|---|
| 60秒 未満 | かんたんすぎ |
| **60〜240秒** | **ちょうどいい** |
| 240秒 以上 | ながすぎ |

そして**必ず600秒まで待ってください**。300秒で打ち切ると、
まだ勝てる戦いを「負け」と数えてしまいます（v4.3で実際にやらかしました）。

決めているのは敵城の体力ではなく、**「前線を突き破れるか」**です。
時間を延ばしたいときは `castleHp` ではなく `power` と**敵の湧く量**を触ります。

### 2. レベルは「進捗から実際に貯まる分」を使う

思いつきのレベルで測ると、たいてい**3〜5レベル高すぎ**ます（v4.6・v6.1で経験）。
けいけんちは**全キャラ共通のプール**なので、編成人数で割った分しか上がりません。

その章に着いた時点で、全コースを1回ずつクリアして貯まる実力レベルの目安：

| 章 | 平均 実力レベル |
|---|---|
| 1〜6章 | Lv.1 〜 Lv.9 |
| あき坊の宇宙船 | 1〜5階 Lv.15 ／ 6〜9階 Lv.20 ／ 10階 Lv.25 |
| **10章（木星）** | **Lv.19〜20**（Gコイン267＝ガチャ89回ぶん） |

**実力レベル ＝ レベル ＋ 上限解放（＋）** です。ダブりが多いノーマルほど
＋が伸びるので、レア度が高い子ほど実力レベルは**低く**なります。
（木星の時点でノーマルは＋6前後、でんせつレアは＋0）

### 3. 手持ちは「ガチャを実際に回した結果」を使う

コインの総額からガチャ回数を出し、**本番と同じ抽選ロジック**で引きます。
木星の時点なら、ノーマル・レアは全部そろい、げきレア4種のうち約4体、
スーパーレア2種のうち約2体、でんせつレアは**約6割の人が持っている**くらいです。
最初から全部持っている前提で測ってはいけません。

### 4. 編成とコストの帯

**壁（タンクン・かべくん）は必ず入れます。** そのうえで、
コストの帯をばらけさせてください（安いのばかりでも高いのばかりでもダメ）。

```
〜300円   3体   … 壁・数で押す子
300〜700円 3体   … 主力
700〜1300円 2体  … 重い主力
1300円〜   2体   … 切り札
```

### 5. 出撃のさせかた

1. **安い壁は切らさない**（いつでも出せるなら出す）
2. **残りは高い子から先に出す**

これをしないと、安い子にお金を取られて切り札が一生出せず、
「本当は勝てる戦い」を「勝てない」と誤判定します（v5.4の教訓）。

### 6. しんかは必ずさせる（v6.7.1の教訓）

実際のプレイヤーは **Lv.10 になったら必ず進化させています**。
進化なしで測ると、まるで別のゲームの数字になります。

| ドズル社プラネット | しんかあり | しんかなし |
|---|---|---|
| 1 ゆきの ひろば | 143秒 勝10/10 | **10戦 全敗** |
| 3 マグマの みずうみ | 203秒 勝9/10 | **10戦 全敗** |
| 5 社長室への かいだん | 170秒 勝9/10 | 255秒 勝1/10 |

同じ理由で、**編成を選ぶときの強さ比べも進化後の姿でやります**。
そして**進化後のコストで出撃させてください**。
マッチくんは 105円ですが、進化すると

```
マッチくん 105円 → オレマッチくん 160円 → 炎のダンサー マッチ様 600円
たたみん   200円 → 柔道少年たたみん 300円
```

進化前の値段で「安いから壁」と判断すると、お金が一生足りず、
**その子の枠が毎ターン空回りして他の子まで出せなくなります**
（v6.7 の測定はこれで数字が狂っていました）。

### 7. とくせつコースは勝率で合わせる

**時間の基準（60〜240秒）はふつうの章（1〜10章）用です。**
とくせつコース（ドズル社プラネットなど）は**高難度コース**なので、
時間ではなく**勝率**で合わせます。

| | 目安 |
|---|---|
| ふつうのステージ | **30回やって20回勝つ**くらい |
| 最終ステージ（おおボス） | **30回やって15回勝つ**くらい |

勝率をここまで上げると、勝った試合でも**3〜8分**かかります。
そこは**そういうものとして許容します**（切り札のぶつけ合いになるため）。
時間の基準をここに当てはめて弱くしてしまわないでください
（v6.7.1で実際にやらかしました。29勝/30戦まで甘くしていました）。

**`power` の効きかたは崖のように急です。** 実測例：

```
ステージ4  power 4.6 → 30勝/30    4.8 → 20勝/30    5.0 → 6勝/30
ステージ5  power 3.5 → 21勝/30    3.8 →  5勝/30
```

0.2 動かすだけで全滅します。**0.05〜0.1 きざみ**で探してください。

### 8. 何回まわすか

ボス戦は**ばらつきがとても大きい**です。同じ設定でも中央値が
232秒と326秒に振れたことがあります。さらに v6.7.1 では、
同じ設定・16回でも中央値が **203秒と335秒** に振れました。
ボスのいるコースは**30回**、ふつうのコースでも**20回**は回してください。
勝率で合わせるときも、**同じ設定で30戦を2回**まわして
15/30・16/30 のように**2回とも5割前後になること**を確かめます。

**負け・時間切れは「600秒」として数に入れてから中央値を取ります。**
勝った試合だけで中央値を取ると、遅い試合が消えて
「弱くしたのに時間が伸びた」という嘘の結果になります。

| | 使い道 | もらえかた |

## 太陽（ボス＆中ボスラッシュ・v6.11）

宇宙地図の**右端の矢印**を押すと、横にスライドして「太陽 ちず」に移ります。
戻るときは太陽側の左矢印。宇宙の星を全クリアすると矢印が出ます。

| | ステージ | 出てくる順番 | power |
|---|---|---|---|
| 12-1 | ほのおの もん | 下手なきりん → ガラク帝 → お菓子マン | 18 |
| 12-2 | ひかりの かいろう | 覚醒ヌシノオオカミ → 覚醒メルトギア → ゼノス | 10.3 |
| 12-3 | 太陽の いただき | 覚醒ガオウ → 覚醒賢者カロン → 帝王クモール → **闇堕ちあき坊** | 5.4 |

**雑魚が1体も出ません。** ボスは時間ではなく `atCastleHp` で呼び出すので、
`holdBossFloor()` が城の体力を支え、**1体ずつ順番に倒していく**形になります。

### このコースだけ難易度の測り方が違う

ボスだけのステージは**壁が持つので「負け」がほとんど出ません**。
代わりに「倒しきれず600秒たっても終わらない＝クリアできない」が失敗になります。
実測（30戦を2回）：

| | 1回目 | 2回目 | 勝ったときの時間 |
|---|---|---|---|
| 12-1 | 19/30 | 19/30 | 474秒 |
| 12-2 | 12/30 | — | 600秒以上が半分 |
| 12-3 | 11/30 | 14/30 | 600秒近く |

**硬いほど長くなるのが避けられません。** 難しさの源がボスの体力しかないので、
「短くて厳しい」は作れず、「長くて厳しい」になります。ボスラッシュというジャンル上
そういうものとして許容しています。power を下げると一気に100%クリアに戻ります
（12-1 は 8 で 100%・165秒）。

### 世界（world）の増やしかた

`CHAPTERS` の `world` は `'earth' / 'space' / 'sun' / 'storm'` の4つ。
`chapterOpen()` が世界ごとに解放条件を分けています
（sun は宇宙を全クリア＝`spaceAllCleared()`、storm は太陽を全クリア＝`sunAllCleared()`）。
矢印は `#btn-map-right` / `#btn-map-left`、スライドは `redrawMap(dir)` の
CSSアニメーションです。

## あいしょうひょう（`#screen-attr` / v6.27）

ホームの「あいしょうひょう ⚖️」。`js/data.js` の `ATTR_BEATS` / `CONFIG.attrStrong` /
`attrPairMultiplier()` と**同じ内容を絵にしたもの**です。数字を変えたらここの文言も直します。

| パネル | 中身 |
|---|---|
| ① 2つの わ | みず→ほのお→くさ→みず ／ まじゅつし→パワー→けもの→まじゅつし |
| ② メタル | 得意な相手なし。ほのお・まじゅつし・パワーに狙われる |
| ③ かみ | 全部に1.2倍・被ダメ0.8倍、メタルにだけ0.6倍（メタル→かみは2.5倍） |
| ④ む・ゆうれい | 相性なし。ゆうれいは代わりに「むこうか」 |

描画は canvas。`attrNode()` が玉＋アイコン＋名前、`attrArrow()` が「強い向き」の矢印、
`attrChip()` が「2.5ばい」などの札です。

- **名前は文字幅を測って**玉に被らない位置に置きます（`ctx.measureText`）。決め打ちの
  オフセットだと「まじゅつし」のような長い名前が玉に重なります。
- レイアウトは**横長なら左右に2つ、縦長なら上下に2つ**（`drawAttrRings` の `wide` 判定と
  `paintAttrCanvas` に渡す ratio 関数が連動しています）。
- 輪は「わく（x0,y0,幅,高さ）」に収める形で描くので、枠の比率が変わってもはみ出しません。
  横並びのときは隣の輪の名前とぶつからないよう、使う横幅を 0.84 に抑えています。

## 顔アップの切り取り（`paintCharBust` / v6.21・v6.26）

**戦闘中の味方ボタン（`.u-icon`）と パワーアップ画面の行（`.power-row canvas`）**は、
絵の**上のほうだけを切り取って**顔を大きく出します。この2画面は同じ関数を使うので、
枠の大きさが違っても framing はそろいます。

（全身を見せたい画面 ── 編成・図鑑・ガチャ ── は `paintChar` のままです。）
キャラの背丈はバラバラなので、切り取る枠は `bustBox()` が**実際に描いて画素から測って**決めます。

測りかた（`js/main.js`）:

1. 240×240 のオフスクリーンに 0.75 倍で一度描く。
2. 上端は **α>180 のしっかり塗られた画素**から測る（あき坊の淡いオーラに引っぱられないため）。
3. 切り取る高さ `cutH` = **「絵の高さの55%」と「52」の小さいほう**（下限28）。
   55%だけだと、背の高いスティーブ・アイアンゴーレム・ドンドコ力士・あき坊が
   **体ばかりで顔が小さく**なっていました。
4. 横幅は**切り取った帯の中だけ**で測る（下で広げた腕や尻尾に引っぱられない）。
5. 横の中心は、帯の上45%（＝顔）にある画素の**重心**。弓や杖のような細い線は
   画素数が少ないので中心がずれません（スティーブの弓、マッチ様の炎）。

結果は `bustBoxCache` に覚えるので、1キャラにつき1回しか測りません。

`.unit-btn canvas` / `.pslot canvas` / `.room-item canvas` / `#story-canvas` は
**`flex:1 1 0; min-height:0;`** です。`flex:1 1 auto` だと `canvas` の `width`/`height`
属性（＝ビットマップの大きさ）がレイアウトの基準になってしまいます。

## 1日1回のごほうび ── 夜0時リセット（v6.33）

ネコスの店（素材5個）とミニゲーム2本のごほうびが対象です。

**v6.32まで**：`at + 86400000 > Date.now()` ── 「もらってから24時間」。
夜遅くにもらうと翌日は夜までもらえず、遊ぶ時刻がだんだん後ろにずれていく問題が
ありました。

**v6.33から**：`slot()` に入れた時刻の**カレンダー上の日付が今日かどうか**だけを見ます。

```js
function dayKeyOf(ts) {                 // 2026-09-19 → 20260919
  const d = new Date(ts);
  return d.getFullYear() * 10000 + (d.getMonth() + 1) * 100 + d.getDate();
}
function gotToday(at) { return !!at && dayKeyOf(at) === dayKeyOf(Date.now()); }
```

- `nekosReady()` = `!gotToday(slot().nekos.at)`
- `miniRewardReady(key)` = `!gotToday(slot().mini[MINI_AT[key]])`
- 残り時間の文言は `nextDayText()` ＝「あした 0時（あと ○時間 ○分）」

保存する値（`at` / `catchAt`）は前と同じ `Date.now()` なので、**古いセーブもそのまま
動きます**。端末の時計（タイムゾーン）で数えます。`Date` の月は0始まりなので `+1`。

**庭のレベルアップ（24時間ごとに＋1）はこれまでどおり**です。あちらは「1日1回の
ごほうび」ではなく経過時間を積み上げる仕組みで、`floor((now - since) / 24時間)` で
まとめて加算するため、日付境界に合わせる意味がありません。

### ケダマールとの たいけつ（3つめ・v6.38）

だい17しょう「埃にまみれた都市」を全クリアすると解放（`chapterAllCleared(17)`）。
**Undertale のサンズ戦**を参考にした、ターン制の弾幕回避バトルです。

```
　敵のターン … 四角い枠の中で「魂」（赤いハート）をスティックで動かして避ける
　　　　↓
　自分のターン … たたかう / みを まもる / しらべる を選ぶ
　　　　↓　　（「たたかう」は動く針を真ん中で止めるほど高ダメージ）
　　繰り返し → ケダマール 120 を削りきれば勝ち / 自分の 20 が尽きたら負け
```

**仮想スティック**（`#duel-stick`）は `pointerdown` → `pointermove` でノブを追わせ、
中心からのずれを `DG.vx / DG.vy` にしています。`setPointerCapture` を使うので
指が枠の外に出ても追従します。`pointerup` / `pointercancel` / `lostpointercapture` の
3つ全部で中立に戻さないと、指を離しても動き続けます。

**16方向スナップ（v6.39）**：倒した「向き」だけを 22.5°刻みに丸め、「強さ」
（中心からの距離 0〜1）はそのまま使います。

```js
const mag = Math.min(1, Math.hypot(dx, dy) / max);
if (mag < DUEL.stickDead) { DG.vx = 0; DG.vy = 0; return; }   // 中心16%は無反応
const step = Math.PI * 2 / DUEL.dirCount;                      // 16方向
const ang  = Math.round(Math.atan2(dy, dx) / step) * step;
DG.vx = Math.cos(ang) * mag;
DG.vy = Math.sin(ang) * mag;
```

実測（実際に指を動かして `DG.vx/vy` を読んだもの）:

| 入れた角度 | 出た角度 |
|---|---|
| 0° / 8° | **0°**（真横） |
| 14° / 24° / 33° | 22.5° |
| 45° | 45° |
| 70° | 67.5° |
| 90° / 100° | **90°**（真上・真下） |

少しくらい斜めでも真横に走るので、狙った位置で止めやすくなります。
中心の無反応域は **青い毛のターンでうっかり動かないため**にも効きます。

| 攻撃 | 中身 | 元ネタ |
|---|---|---|
| `rain` | 毛玉が上から降る | 骨の雨 |
| `spike` | 上下から毛のトゲの壁。**隙間が1か所** | 骨の壁 |
| `blaster` | 1秒光ってからレーン全体をビームが薙ぐ | ガスターブラスター |
| `blue` | **青い毛（止まる）と白い毛（避ける）が交互** | 青い骨＋白い骨 |
| `sweep` | 横から毛の壁が流れる。隙間が1か所 | 横向きの骨 |
| `gravity` | **青い魂。重力で床に落ち、ジャンプで骨を越える** | 青いSOUL |
| `flip` | 同上＋**3秒ごとに重力が反転**（床が天井になる） | サンズの重力反転 |

1周するごとに `hard = 1 + lap * 0.18` で速くなります。

### 青い魂＝重力＋ジャンプ（v6.40）

Undertale の青いSOUL（パピルス戦で登場し、サンズ戦では重力反転まで使われる）
と同じ仕組みです。

### 枠の外から迫ってくるように見せる（v6.41）

### ★この章の設計で一番大事なこと ── たつまき砲がすべてを支配する

ユーザー指定で**7コースとも「たつまき砲」あり**。実測するとこれが**難易度のほぼ唯一の
主役**でした。15-1 で比べると:

| | クリア時間 |
|---|---|
| たつまき砲なし | **78秒** |
| たつまき砲あり（18秒/67%） | **250〜300秒**（power や castleHp をどういじってもほぼ変わらない） |

18秒ごとに前線が6〜7割消えるので、**敵の強さではなく「押し切れるかどうか」**で時間が
決まります。だから:

1. **たつまき砲を1コースずつ強くするランプ**にしました（34秒/40% → 24秒/60%）。
   これがこの章の難易度カーブの本体です。
2. **重ねがけになる敵は置けません。** 最初カマジロウを範囲110・atk420 にしたら、

#### ステータスの考えかた

原作のサンズは「**1ダメージしかないが、絶対に当たらない**」キャラです。
そのまま数字にすると味方として使いものにならないので、
**紙耐久＋高回避＋長射程＋継続ダメージ**という形に置きかえました。

| | サンズ | サンズ（ほんき） | 比較：あき坊(LR) |
|---|---|---|---|
| コスト | 1450 | 1450 | ─ |
| 再生 | **200秒** | 170秒 | ─ |
| 体力 | **950** | 1200 | 5000超 |
| 攻撃 | 430 | 720 | ─ |
| 射程 | **235** | 255 | 210 |
| 範囲 | 95 | 115 | ─ |
| 回避 | **60%** | **70%** | ─ |
| multiHit | 2発 | 2発 | ─ |
| KARMA | 6秒・30%/秒 | 7秒・40%/秒 | ─ |

- **体力950** は LR で最低です。ノックバック2回で、殴られれば一瞬で消えます。
- そのかわり `dodge: 0.60` で**6割は当たりません**。「あたらなければどうということはない」。
- `range: 235` は味方最長クラス。**あき坊(210)・おおはらMEN(200)より外側**から撃ちます。
  第16〜17章で何度も出た「**射程の崖**」を、今度は味方側に作った形です。
- `burn: { chance: 1.0, ... }` が **KARMA**。「必ず付く」火傷として表現しました。
  硬い相手ほど効きます。
- **再生200秒**（ゲーム最長）が唯一のブレーキです。ずっと寝ているから。

`attr: 'ghost'` は相性の輪の外側なので、**どの属性にも不利を取りません**。
そのかわり有利も取りません。

止まらずに進む」動きなので、味方の群れのど真ん中に飛び込んで溶けていたのです。

そこで `flyOver: false` を付け、**前にいる相手を早めに見つけて射程150から範囲攻撃**
する形にしました（攻撃力も 215→265）。攻撃時は `s.atk` を見て羽を大きく広げ、
爪の切り跡が飛びます。

**これが第17章の数値を全部作り直す羽目になった原因です。** 突っ込んで死ぬ敵と、
前線を遠くから叩き続ける敵では、強さが桁違いでした（17-2 は一度 **0/30** になりました）。

### ★★ 敵を倒すのがプレイヤーの収入源 ── 弱くすると逆に長引く ★★

第15〜17章で何度も「**敵を弱くしたら中央値が伸びた**」という逆転に出くわしました。

| 例 | 変更 | 結果 |
|---|---|---|
| 15-7 | power 1.9 → 1.4 | 40% → **0%** |
| 17-1 | ハネネコ hp760→640・atk265→245・間隔2.3→2.8 | 355秒 → **376秒** |

原因は `Game.killUnit()` の `this.money += u.def.money` です。**敵を倒すこと自体が
お金の主な入手源**なので、敵を弱く・少なくすると味方を出すお金が回らなくなり、
かえって押し切れずに長引きます。逆に敵が多いほど経済が回って速く終わることがあります。

なので**時間を縮めたいときに「敵を弱くする」は効きません。** 効くのは:

1. **敵の射程**（下の節 ── これが一番効く）
2. 倒したときの `money` を上げる（倒しにくい敵ほど高くする）
3. 出現数を**増やす**（減らすのではなく）

### ★ボスの射程が長すぎると「200秒間無傷」になる

第15章のハッチー(150)・第16章のガレキマル(265)と**同じ罠に3回目**で気づきました。
20秒ごとの経過を出したら、ケダマールの体力が**40秒から240秒までぴったり36000のまま**
でした。射程205は味方のほとんど（あき坊210・おおはらMEN200以外）が届かないので、
ボスが一方的に撃ち続けるだけの時間が200秒続いていたのです。

| 変えたところ | 結果（20戦） |
|---|---|
| 範囲 175→115・吹き飛ばし 35%→30% | 414秒 → 428秒（**効かない**） |
| 城の体力 2700→2200 | 414秒 → 407秒（**効かない**） |
| **射程 205→150** | 414秒 → **377秒** |

**射程だけが効きます。** power も城の体力も範囲も、ほとんど時間を変えません。
同じことをチューチューでも確認しています（v6.35）。

## ボスの立ち回り（v6.35）── 飛び越えない／早めに出る

### `flyOver: false` ── 飛んでいるが味方を飛び越えない

`flying: true` は今まで**「壁を越えて一番奥の相手を狙い、止まらずに進み続ける」**
（カモメェル用）という意味でした。チューチューもこれを持っていたので、
**ボスが自分の城を放り出して飛んでいってしまい、城ががら空きになる**という
問題が起きていました。

`flyOver: false` を書くと、**見た目は飛んだまま**、狙いかたは普通の敵と同じ
（前にいる相手から順番）になります。カモメェルとハッチーは今までどおりです。

### チューチューの再調整（これがないと勝てない）

前線で戦うようになった途端、**30戦して0勝**になりました。原因は3つで、
どれも「囲まれたときに強すぎる」性質です。

| | 前 | 後 | 理由 |
|---|---|---|---|
| 吸血 | 当てた**全員**から | **1回の攻撃につき1体ぶん** | 範囲攻撃で5体に当てると5倍回復し、600秒経っても体力がほぼ減りませんでした（下の実測） |
| 回避 | 50% | **30%** | 実質体力が2倍になり、吸血と合わさって不死身に |
| 範囲 | 150 | **95** | 1.85秒ごとに前線がまとめて消える（カマジロウと同じ罠） |
| コースの power | 1.9 | **1.5** | |

600秒時点のボスの体力 ── **吸血の上限を入れる前：28567/29070（ほぼ無傷）→
入れた後：5536/29070**。効いたのはこの1点でした。

`drain.all: true` と書けば今までどおり全員から吸えます（今は誰も使っていません）。

**power はほとんど効きません。** 1.9→1.4→1.1 と下げても勝率は 40%→0%→13% と
バラバラでした（敵を倒すとお金が入るので、敵が強いほうが逆に有利になる場合がある）。
効いたのは**範囲**（40%→73%）です。

### `hold` ── ボスを早めに出し、出るまで城を削らせない

ユーザー指定「ガオウドウが何もできずに死んでしまう」への対応です。
`atCastleHp` だと**プレイヤーの大軍が城に着いた瞬間**にボスが湧くので、
その中に出てきて何もできずに溶けていました。

```js
{ at: 40, id: 'gaoudou', count: 1, hold: 0.62 },   // 40秒で登場
{ at: 40, id: 'gaou_ko', count: 4, gap: 1.1 },     // 護衛の子ども4体
```

`hold` は `holdBossFloor()` が見ます。**そのウェーブが出るまで、城の体力を
その割合より下に落とせません**。ボスは中盤に子分を連れて出てきて、
前に出て戦ってから城に戻ります。

| | 前 | 後 |
|---|---|---|
| 15-7 チューチューの巣 | 26/30・166秒（※ボスは飛び去っていた） | **25/30・436秒** |
| 16-7 ガオウドウのひろば | 30/30・221秒 | **30/30・301秒** |

15-7 が長くなったのは、**ボスが本当に城を守るようになったから**です。

### たつまき砲（`stage.tornado`）

```js
tornado: { interval: 18, chance: 0.67, first: 14 }
```

`Game.updateTornado()` / `Game.fireTornado()` が実装です。

- `first` 秒後に最初の1発、以後 `interval` 秒ごと。
- 撃つ **1.2秒前に画面中央へ「たつまきほう！」** の予告が出ます（`camera.x` に出すので
  どこを見ていても見えます）。
- 発射すると `tornadoBlast` が生まれ、**敵の城（x = −70）から右へ 0.9秒でフィールドを
  渡りきる**速さで走ります。絵は `drawStormTornado()`（写真のとおりの本物の渦巻き）。
- 竜巻が**通り過ぎた味方から順に**判定します。対象は**場にいる味方全員**で、
  `chance`（67%）なら**即死**（`u.hp = 0; u.dead = true;`）。
  当たれば「とばされた！」、耐えたら「たえた！」。
  一度判定した相手は `u.tornadoMark` で覚えるので二重には当たりません。
- 走らせても勝率は変わりませんでした（掃過が0.9秒と短く、味方は前線に固まっているため）。
  実測も 18/60 のままです。

平均して6〜7割の味方が消えるので、**出すタイミングの読み合い**がこのステージの中身です。
予告のあいだに壁を足すか、貯めてから一気に出すかで結果が変わります。

- 24時間たつ前に別の子に変えると、途中まで貯まった分は消える
- **1体につき＋10まで**
- この＋はガチャの上限解放（＋30）とは**別枠**で上乗せ

```
実力レベル ＝ min(Lv.30 + ガチャ＋30) + にわ＋10   → 最大 Lv.70
```

`s.gardenPlus[キャラid]` に貯め、`effLevel()` が加算します。
`s.garden.since` が「今の子を選んだ時刻」で、`gardenTick()` が
`floor((now - since) / 24時間)` だけ加算して `since` をその分だけ進めます
（余った時間は残るので、23時間59分で損をすることはありません）。

実測で確認：23時間→＋0、24時間→＋1、5日→＋5、＋8から5日→＋10で打ち止め。

ボス戦や敵が群れるコースで効いてきます。

```js
burn: { chance: 1.0, dpsRate: 0.20, duration: 4.0 },
//     ↑必ず       ↑与えたダメージの20%  ↑4秒間
```

`dpsRate` を使うと、**レベルが上がると炎上のダメージも一緒に強くなります**

> **⚠ コストと再生産時間について（実験でわかったこと）**
> 範囲攻撃と炎上を持ったまま 110円・4秒のままにしたら、

> セットで見直してください。
>

> 9回中6回負けます。高い子が死ぬとお金が立て直せないからです。
> **性能はそのままで、コストと再生産だけ上げる**のが正解でした。
>
> | 設定 | 10-7 ボス | 判定 |

> | 110円／4秒 | 78秒 | かんたんすぎ |
> | 150円／6秒 | 246秒 | まだ序盤が40〜60秒 |
> | **600円／30秒** | **166秒** | **全コース60〜240秒に収まる** |

## 2つの属性を持つ敵

```js
attr: ['fire', 'magic'],   // 獄熱オニごん（炎＋魔導士）
```

**ポケモンと同じ考えかた**で、関係があるぶんを**ぜんぶ掛け算**します。
1つでも不利があればダメージは落ち、有利が重なるほど通りやすくなります。

```
みずで殴る   → 炎に有利(2.5) × 魔導士には等倍(1.0) = 2.5倍
けもので殴る　 → 炎に等倍(1.0) × 魔導士に有利(2.5) = 2.5倍
くさで殴る   → 炎に不利(0.6) × 魔導士には等倍(1.0) = 0.6倍
メタルで殴る → 炎に不利(0.6) × 魔導士にも不利(0.6) = 0.36倍
```

獄熱オニごん（炎＋魔導士）の場合：

| 味方の属性 | ボスへ与える | ボスから受ける |
|---|---|---|
| **みず・けもの** | **2.5倍** | **0.6倍** |
| む・ほのお・まじゅつし | 1.0倍 | 1.0倍 |
| くさ・パワー | 0.6倍 | 2.5倍 |

**みずかけものを連れていくのが正解**です。2.5倍を通しながら、受けるダメージは0.6倍で済みます。

## ふところの間合い（minRange）

```js
range: 300,        // ここまで届く
minRange: 130,     // これより近いと攻撃できない
```

味方が1体でも `minRange` の内側に入ると、その敵は**攻撃も前進もできなくなります**（獄熱オニごん）。
壁役を先に送り込んで懐にもぐりこむのが攻略法です。

## 新しい特殊能力の書きかた（`js/data.js`）

```js
/* ぞくせい きゅうしゅう：きめた属性の攻撃はダメージ0。そのぶん回復する */
absorb: { attrs: ['water'], rate: 1.0 },   // rate 1.0 = ダメージと同じだけ回復
                                           // rate 0.5 なら半分だけ回復

/* クリティカル：かくりつで ダメージばいぞう */
crit: { chance: 0.15, mult: 3, ignoreAttr: true },
//     ↑15%       ↑3ばい  ↑true にすると属性の相性(2.5倍/0.6倍)を無視して
//                          「こうげきりょく × 3」きっかりのダメージになる
//                          false や 書かない ときは 相性のあとに かけ算

/* かくりつ ノックバック */
knockbackChance: 0.35,                     // 0.35 = 35%

/* こうげきりょくを さげる（たぬポン・クマった・メルトギア）*/
weaken: { chance: 0.30, rate: 0.6, duration: 3.0 },   // 30%で 攻撃力60%に 3秒

/* ピンチで 1度だけ 回復（コケジカ）*/
healOnce: { below: 0.5, rate: 0.3 },       // 体力50%以下で 最大体力の30%回復

/* ピンチで強くなる（ヌシノオオカミ・ガラク帝・ガオウ・メルトギア）*/
enrage: { below: 0.5, atkMult: 1.5 },      // 体力50%以下で攻撃力1.5倍
enrage: { below: 0.4, intervalMult: 0.6 }, // 体力40%以下で攻撃間隔0.6倍（＝速くなる）

/* ノックバック無効（ガオウ・ガラク帝・メルトギア）*/
kbImmune: true,

/* とくいな相手に追加ダメージ（モエリス）*/
bonusVs: { attrs: ['grass'], mult: 1.4 },  // 草の相手に さらに1.4倍

/* 炎上：じわじわダメージ（フレイムメイジ）*/
burn: { chance: 0.20, dps: 60, duration: 3.0 },   // 20%で 毎秒60を3秒＝180ダメージ

/* 攻撃を封じる（カオススペル）… blind の missRate を 1.0 にする */
blind: { chance: 0.20, duration: 5.0, missRate: 1.0 },

/* じゃまを 無効にする（柔道少年たたみん）*/
kbImmune: true,     // ふきとばし 無効
slowImmune: true,   // 鈍足 無効（クモの巣の鈍足もふくみます）
stunImmune: true,   // 動きを止める効果 無効

/* きめた属性のダメージを抑える（たたみん）*/
resist: { attrs: ['water'], mult: 0.2 },   // 水の攻撃を20%まで下げる
                                           // ふつうより小さくなるときだけ効きます

/* クモの巣：まえの ほうに 巣を はって、なかの相手をずっと鈍足にする（帝王クモール）*/
web: { interval: 8.0, ahead: 420, radius: 150, slowRate: 0.45, duration: 5.5 },
//     ↑8秒ごと    ↑自分から420前  ↑巣の広さ  ↑速さ45%に      ↑5.5秒で消える
```

**クモの巣のコツ** … `interval` を `duration` より**大きく**しておくと、巣が消える
「すきま」ができます。ここが前に押しこむチャンスになるので、ここを縮めると一気に難しく
なります（`interval` ≦ `duration` にすると巣が張りっぱなしになり、にらみ合いのまま
終わらなくなることがあります）。

## レア度と強さの傾斜

レア度が高いキャラほど**1体あたりの絶対的な強さ**が上がります。
ただし**コストと再生産時間も上がる**ので、「安く数を出す」のはノーマル・レアの役目です。

### 総合力の出しかた

```
総合力 ＝ √( 実質の毎秒ダメージ × 体力 )

実質の毎秒ダメージ ＝ 攻撃力 × 連撃数 ÷ (攻撃間隔 ＋ 振りかぶり) × 範囲ばいりつ
                     範囲ばいりつ … 範囲攻撃なら 1.6、単体なら 1.0
```

かけ算のルートを取っているので、**攻撃と体力の両方がある子ほど高く出ます**。
どちらかに偏った子は、合計が同じでも低く出ます。

**この数字に入っていないもの**（＝数字より実際は強い／弱いことがあります）

| 入っていないもの | 影響を受けるキャラ |
|---|---|
| コストと再生産時間 | 安いタンクンは数を出せるぶん、数字より強い |
| 射程 | スティーブ（射程1000）は数字より かなり強い |
| 特殊能力 | かべくん（攻撃0で50）、ぷりお（足止め）は数字より強い |

### レア度ごとの目安

新しいキャラを作るときは、この幅に収まるように数値を決めます。

## 属性の相性（じゃんけんが2つ）

```
【わ その1】 みず → ほのお → くさ → みず
【わ その2】 まじゅつし → パワー → けもの → まじゅつし
【メタル】   ほのお・まじゅつし・パワー の3つに弱い（得意な相手はなし）
【かみ】     どの属性にも 攻撃1.2倍／被ダメージ0.8倍。ただしメタルにだけは弱い
【ゆうれい】 相性はぜんぶ等倍。そのかわり「むぞくせい」と「パワー」の攻撃がきかない
```

### かみ属性（あき坊）

三すくみの外にいる特別な属性です。**すべての属性に少しだけ有利**ですが、
**メタルにだけは通常の弱点あつかい**（与える0.6倍／受ける2.5倍）になります。

| | かみが与える | かみが受ける |
|---|---|---|
| メタル以外 ぜんぶ | **1.2倍** | **0.8倍** |
| メタル | **0.6倍** | **2.5倍** |

倍率は `CONFIG.godAtk` / `CONFIG.godDef` で変えられます。

## ゆうれい属性（霊太郎）

相性は**すべて等倍**です。そのかわり **むぞくせい と パワー の攻撃をすりぬけます**（ダメージ0）。

```js
attr: 'ghost',
nullify: { attrs: ['none', 'power'] },
```

**大事なルール**：2つの属性を持つ敵（バーナー君＝メタル＋炎 など）の攻撃は**すりぬけできません**。
無効になるのは「その属性ひとつだけ」で殴ってくる相手だけです。

むぞくせいの敵はとても多い（トゲハヤさん・ブロック・ワン・ニョロリ〜ヌ・ほしくん・
ハコボット・ヤマネム・カモメェル）ので、**その並びに対しては無敵の壁**になります。

## 波動（あき坊）

にゃんこ大戦争と同じ考えかたです。**攻撃が当たったとき、前方へ波が走り、
通り道にいる敵ぜんぶに同じダメージ**を与えます。レベルが高いほど遠くまで届きます。

```js
wave: { level: 5, damageRate: 1.0 },   // レベル5・攻撃力と同じダメージ
```

届く距離は `CONFIG.wave.step` × レベル（今は 120 × 5 ＝ **600**）。
射程210と合わせると、**戦場のだいたい8割**に届きます。

- 有利なとき **2.5倍**（ダメージ数字が **赤** で大きく出ます）
- 不利なとき **0.6倍**（ダメージ数字が **グレー** で出ます）
- **2つの輪は別々**。輪をまたぐ組み合わせ（例：ほのお vs けもの）は等倍
- `む`（タンクン・ぷりおぷりねこ・ずにお）はどの属性とも相性なし
- `メタル` は**弱点が3つある代わりに基礎能力が高い**タイプ

倍率は `CONFIG.attrStrong` / `CONFIG.attrWeak`、相性そのものは `ATTR_BEATS` で変えられます。

## キャラの絵を差しかえたいとき

`js/draw.js` の中に、キャラ1体につき関数が1つあります（例：`drawHiibou`）。
中身を書きかえれば見た目が変わります。画像ファイルに差しかえる場合も、
この関数の中を `ctx.drawImage(...)` に置きかえるだけでOKです。

- 原点 `(0, 0)` はキャラの**足もとの中央**
- 上が **マイナス**、下が **プラス**
- 全員 **右向き**で描く（味方は自動で左右反転されます）

## つくった内容（プロトタイプの範囲）

- セーブデータ3つ（それぞれ別に進行を記録。削除もできます）
- トップ画面（ステージ選択／パワーアップ／編成／ガチャ）
- ステージ（章）を選んでからコースを選ぶ2段構え。クリアすると次のコースが出て、次に挑むコースが光ります
- キャラクター編成（最大10体・並びかえ）／パワーアップ（Lv.1〜10）／ガチャ
- 画面の大きさに合わせてボタンと文字が自動で拡大（iPad対応）
- 時間経過でお金が増える → 上限あり → 「おさいふ君」で上限と速度を強化
- キャラごとのコストと再生産クールタイム（アイコンに残り秒数を表示）
- 召喚したキャラは自動で前進し、射程に入ると自動で戦う
- ノックバック（体力を一定量削られるたびに後退）
- 属性相性（三すくみが2つ）
- 特殊能力：スロー（ぷりおぷりねこ・字一龍）／3連撃（テルテル君）／確率ノックバック（時の旅人・豪傑天むす丸）／範囲攻撃（ひー坊・豪傑天むす丸・saba・下手なきりん）／**行動停止**（お菓子マン）／**クリティカル**（コンガラガーン・シャドウヤマネコ）／**属性吸収**（フタバッポ）
- 敵を倒すとお金がもらえる（属性を持った敵ほど多い。画面に「+95」と表示されます）
- 必殺技「ちゅどーん」（チャージ式、範囲ダメージ＋大きくふきとばす）
- ボス戦（下手なきりん＝1-6、お菓子マン＝1-10・2-1の大ボス。上部に専用HPバー）
- クリア記録（ステージ選択に ⭐ が付きます）
- 倍速（1.0 / 1.5 / 2.0）— 長い戦いをテンポよく
- 「やめる」の確認ポップアップ（考えているあいだは戦闘が止まります）

## 新しい版を公開する手順（作業する人むけ）

数値やキャラを変えたあと、ホーム画面のアプリにも反映させる手順です。

1. **バージョンを2か所そろえて上げる**（ここが要）
   - `js/main.js` の `GAME_VERSION`
   - `sw.js` の `APP_VERSION`

   > `sw.js` の中身が変わらないと、ブラウザが「新しい版が出た」と気づけません。
   > 数値だけ直して `sw.js` を触らないと、更新のおしらせが出ないので注意。

2. **GitHubに反映**
   ```bash
   git add -A
   git commit -m "v1.6 〇〇を調整"
   git push
   ```

3. 1〜2分でサイトが切りかわります。ゲームを開いている人の画面には
   **「✨ あたらしい バージョンが あります」**の帯が自動で出ます
   （開いているあいだ5分おきに確認しています）。

公開先: https://github.com/akihikoito-apps/gounosuke-game
