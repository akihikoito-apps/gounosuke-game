# ごうのすけのゲーム

スマホのブラウザで動く、オリジナルキャラのタワーディフェンスゲーム。

**遊ぶ → https://akihikoito-apps.github.io/gounosuke-game/**

## あそびかた

上のURLを開くだけです。**横向き（よこ持ち）推奨**。

パソコンで確認するときは `index.html` をダブルクリックでも動きます（サーバー不要）。

### iPad / iPhone のホーム画面に入れる

1. **Safari** で上のURLを開く
2. 右上の**共有ボタン**（□に↑）をタップ
3. **「ホーム画面に追加」** → 「追加」

アイコンから起動すると全画面のアプリになり、**一度開いたあとはネットがなくても遊べます**。

## ずかん

トップ画面の **「ずかん 📖」** から開けます。

- **みかた / てき** をタブで切りかえ
- **属性**（10種類）と **レア度**（味方のみ）でしぼりこみ
- 1体ずつ **絵・基本ステータス・属性・レア度・特性の説明** が出ます
- ステータスは **★5つの目安と数字の両方**で出ます

```
たいりょく        ★★★☆☆  1900
こうげき          ★★★★☆  500
1びょうの ダメージ ★★★★☆  182
しゃてい          ★★☆☆☆  118
うごく はやさ      ★★☆☆☆  24
こうげきの はやさ  ★★★☆☆  2.8びょうに 1かい
だしやすさ        ★☆☆☆☆  コスト 1350
```

★の数は `STAR_SCALE`（`js/data.js`）で決まります。境目の数字を書きかえれば
図鑑の★も変わります。「こうげきの はやさ」と「だしやすさ」は
**小さい数字ほど★が多い**ように、境目を大きい順に書いています。

```js
const STAR_SCALE = {
  hp:    [600, 1500, 3000, 6000],   // 600未満=★1、1500未満=★2 …
  cycle: [3.6, 2.8,  2.0,  1.4],    // 小さいほど良いので大きい順
};
```

**出てきたキャラだけ**が載ります。味方は「持っているキャラ」、敵は
「戦闘で一度でも出会った敵」（`slot.seenEnemies` に記録）です。

戦闘中の **「メニュー」→「キャラ じょうほう」** からも開けます。
そのときは**そのステージに出る味方と敵だけ**にしぼられ、「もどる」で戦闘に復帰します。

特性の文章は `abilityLines()` が数値から自動で作るので、
`js/data.js` の数字を変えれば図鑑の説明も自動で変わります。

### 操作
| やること | どうする |
|---|---|
| セーブデータ | 起動時に3つから選ぶ（× ボタンで削除） |
| ずかんを見る | トップの「ずかん」／戦闘中は「メニュー」→「キャラ じょうほう」 |
| キャラを出す | 画面下のキャラアイコンをタップ |
| おかねを強くする | 左下の「おさいふ君」をタップ |
| 必殺技 | 右下の「ちゅどーん」（チャージが満タンのとき光ります） |
| はやさを変える | 右上の「倍速」ボタン（1.0 → 1.5 → 2.0 → 1.0…） |
| メニュー | 上の「メニュー」→「キャラ じょうほう」「せんとうを やめる」「せんとうに もどる」 |

戦場は**全体が常に1画面に収まる**ので、スクロール操作は要りません。

パソコンで遊ぶときは `1`〜`5` キーでキャラ、`W` でおさいふ君、`スペース` でちゅどーん、`F` で倍速切りかえ。

## ★ 数値をいじりたいとき → `js/data.js` だけ ★

`js/data.js` を開いて数字を書きかえ、保存してブラウザを**リロード**すれば即反映されます。
他のファイルは触らなくて大丈夫です。

### どこに何があるか

| 行のあたり | 中身 | よくいじるところ |
|---|---|---|
| `CONFIG` | 全体のルール | 属性倍率、初期資金、おさいふ君、ちゅどーん、自城HP、**戦場の広さと見えかた** |
| `UNITS` | 味方12体のステータス | コスト・体力・攻撃力・射程・速さ |
| `PARTY` | 画面下に並ぶ順番 | 並べかえ・出撃メンバー変更（最大10体） |
| `ENEMIES` | 敵52体のステータス | 同上 |
| `STAGES` | コース構成（第1〜5章 各7＝35コース） | 敵城HP、敵の出方、背景、報酬、敵の強さ倍率 |
| `TOWER` | あき坊の塔 | 特設ステージ（10階・実装ずみ） |
| `CHAPTERS` | 章の名前と地図の位置 | 名前・アイコン・地図上のx/y |
| `BACKGROUNDS` | 背景の色 | 空・山・地面の色 |
| `LEVEL` | レベルアップ | 必要けいけんち、1レベルの伸び |
| `GACHA` | ガチャ | 必要コイン、上限解放の最大値 |
| `RARITY` | レアリティ | 出現確率 |

### 用語のよみかた（`UNITS` / `ENEMIES` 共通）

| 名前 | 意味 | 大きくすると |
|---|---|---|
| `cost` | 召喚に必要なお金 | 出しにくくなる |
| `recharge` | 次に出せるまでの秒数 | 連打できなくなる |
| `hp` | 体力 | 死ににくくなる |
| `atk` | 攻撃力（1回ぶん） | 強くなる |
| `range` | 射程 | 遠くから一方的に殴れる（**いちばん効く**） |
| `speed` | 移動速度（1秒に進む距離） | 前線に早く着く |
| `attackInterval` | 攻撃の間隔（秒） | 攻撃が遅くなる |
| `attackWindup` | 振りかぶってから当たるまで（秒） | 出が遅くなる |
| `kbCount` | 何回ふきとばされるか | ねばり強くなる |
| `areaRadius` | 範囲攻撃の広さ | まとめて当たる |

> **コツ**：強さをいじるなら、まず `range`（射程）を触るのがいちばん体感が変わります。
> 次が `atk` と `attackInterval`。`hp` は最後でOK。

### よくある調整のレシピ

**「かんたんにして」**
```js
playerCastleHp: 4500,   →  8000     // 自分の城をタフに
startMoney: 250,        →  800      // 最初からお金持ち
```
```js
// STAGES の castleHp を減らす（敵の城が早く落ちる）
castleHp: 4300,  →  2500
```

**「画面の見えかたを変えたい」** — `CONFIG` で調整できます
```js
fieldLength: 1050,   // 戦場の長さ。小さくすると接近戦になり、キャラが大きく映る
charScale:   1.5,    // ふつうのキャラの大きさ
bossScale:   1.0,    // ボスだけの大きさ（別あつかい）
groundLine:  0.62,   // 地面の高さ。大きくすると下の余白が減り、キャラの上に余裕ができる
```
戦場の幅は `fieldLength` だけ見ればOKです。**画面の拡大率は自動計算**されるので、
`fieldLength` をいくつにしても横スクロールは発生しません（`castleMargin` と `viewWidth` は
自動調整用なので触らなくて大丈夫です）。

**「むずかしくして」**
```js
// ENEMIES の hp / atk を上げる、または STAGES の repeat を短くする
{ at: 50, id: 'togehaya', count: 2, gap: 2.5, repeat: 22 },  → repeat: 12
```

**「ひー坊をもっと強く」**
```js
hiibou: { ... atk: 430  →  600,  areaRadius: 46  →  70 }
```

**「新しい敵の出しかたを変える」** — `STAGES` の `waves` に1行足すだけ
```js
{ at: 70, id: 'honota', count: 5, gap: 0.3 },   // 70秒後に ほのた5体を0.3秒おきに
```

## 育てかた（Gコイン・けいけんち・レベル）

コースをクリアすると **Gコイン** と **けいけんち** がもらえます。

| | 使い道 | もらえかた |
|---|---|---|
| **Gコイン** | ガチャ（3枚で1回） | **初回クリアのみ**。通常1枚／ボス2枚／1-1と1-2は3枚 |
| **けいけんち** | キャラのレベルアップ | **何回クリアしても毎回もらえます**（周回で貯められます） |

- キャラは **Lv.1 〜 Lv.10**
- ガチャで**すでに持っているキャラ**が出ると **「＋1（上限解放）」**。最大 **＋30**
- **じつりょくレベル ＝ レベル ＋ 上限解放**（最大 Lv.40）
- じつりょく Lv.10 で「しんか」ボタンが出ます

### しんか

じつりょく Lv.10 になると、パワーアップ画面に **しんかボタン** が出ます。
**いつでも元に戻せます**（何度でも切りかえOK）。

#### ずにお → ずに太

| | 体力 | 攻撃力 | 攻撃回数 | 合計 |
|---|---|---|---|---|
| ずにお | 420 | 300 | 1発 | 300 |
| **ずに太** | **630（1.5倍）** | **150（半分）** | **3連撃** | **450（1.5倍）** |

1発が半分になるぶん、**3発ぜんぶ当てて はじめて1.5倍**です。
サイコロの目が1から**3（ななめ）**に変わり、ビームも3本になります。

#### ぷりおぷりねこ → ぷりぷりおぷりねこ

| | 体力 | 攻撃力 | 動きを止める時間 |
|---|---|---|---|
| ぷりおぷりねこ | 560 | 34 | 4秒 |
| **ぷりぷりおぷりねこ** | **840（1.5倍）** | **51（1.5倍）** | **8秒（2倍）** |

大きな口を開けた姿になります。**足止めの時間が2倍**になるので、
数を並べると敵の前線がほとんど進めなくなります。

#### タンクン → たんくんDX

| | 体力 | 移動速度 | 攻撃力 |
|---|---|---|---|
| タンクン | 1400 | 26 | 22 |
| **たんくんDX** | **2800（2倍）** | **52（2倍）** | 22（そのまま） |

装甲板（ボルト4つ）を載せ、キャタピラも大きくなります。
**前線に着くのが2倍速くなり、2倍ねばる**壁役です。攻撃力は変わりません。
戦闘画面のボタンでは **たんDX** と短く表示されます。

新しい進化を作るときは、そのキャラに `evolve` を足すだけです。

```js
zunio: {
  ...,
  evolve: {
    name: 'ずに太', shortName: 'ずに太',
    hp: 630, atk: 150,
    multiHit: { count: 3, delay: 0.18 },
    drawAs: 'zunita',            // draw.js の DRAWERS にある絵の名前
  },
},
```

`evolve` に書いた項目だけが差しかわります。書かなかった項目は元のままです。

### レベルの伸びかた（にゃんこ大戦争と同じ考えかた）

1レベルごとに **Lv.1のステータスの決まった割合** を足していきます。
ただし**あるレベルを超えると伸びが半分、さらに半分**になり、
**その「鈍りはじめるレベル」がレア度で違います。**

| レア度 | ＋10%で伸びる | ＋5% | ＋2.5% | Lv.40での倍率 |
|---|---|---|---|---|
| ★ ノーマル | Lv.1〜10 | 〜20 | 〜40 | **2.90倍** |
| ★★ レア | Lv.1〜14 | 〜24 | 〜40 | **3.20倍** |
| ★★★ げきレア | Lv.1〜18 | 〜28 | 〜40 | **3.50倍** |
| ★★★★ スーパーレア | Lv.1〜22 | 〜32 | 〜40 | **3.80倍** |
| ★★★★★ でんせつレア | Lv.1〜26 | 〜36 | 〜40 | **4.10倍** |

**Lv.10までは全レア度が同じ伸び**（1.90倍）なので、序盤の感覚は変わりません。
差がつくのは上限解放（＋）でLv.10を超えてからです。
**レア度が高いキャラほど長くぐんぐん伸びる**ので、集める意味が出ます。

変えたいときは `LEVEL.growth` を書きかえてください。

```js
growth: {
  N:  [[10, 0.10], [20, 0.05], [40, 0.025]],   // [そのレベルまで, 1レベルあたりの伸び]
  SR: [[20, 0.10], [30, 0.05], [40, 0.025]],
},
```

## あき坊の塔（10かい）

`js/data.js` の `TOWER.courses` に 1階〜10階が入っています。
属性の練習をする場所で、階ごとに「効きやすい属性」が決まっています。

| 階 | 出てくる敵 | 効きやすい味方 |
|---|---|---|
| 1 | 無属性だけ | （相性なし・基本の練習） |
| 2 | 無＋炎 | みず（テルテル君） |
| 3 | 無＋水 | くさ（フタバッポ＝水を吸収します） |
| 4 | 無＋草（回復役） | ほのお（ひー坊） |
| 5 | 無＋パワー | まじゅつし（時の旅人） |
| 6 | 無＋獣 | パワー（豪傑天むす丸） |
| 7 | 無＋魔術師 | けもの（シャドウヤマネコ） |
| 8 | 無＋メタル | ほのお・まじゅつし・パワー |
| 9 | すべての属性 | まとめ |
| 10 | すべて＋ボス「スティーブ」 | まとめ |

- **各階クリアで Gコイン2枚**（初回クリアのみ）。10階ぜんぶで **20枚＝ガチャ6回ぶん**
- **10階すべてクリアで スティーブが1度だけ仲間になります。** ガチャには出ません
- 階の強さは各コースの `enemyMult`（全体）と `enemyBuff`（その敵だけ）で調整できます

```js
enemyMult: 1.25,                              // この階の敵ぜんぶを1.25倍に
enemyBuff: { usagorilla: { hp: 3500 } },      // ウサ・ゴリラだけHPを3500に
```

`enemyBuff` は元の `ENEMIES` を書きかえません。そのコースに出てくるぶんだけ差しかわります。

## 2つの属性を持つ敵

```js
attr: ['fire', 'magic'],   // 獄熱オニごん（炎＋魔導士）
```

**ポケモンと同じ考えかた**で、関係があるぶんを**ぜんぶ掛け算**します。
1つでも不利があればダメージは落ち、有利が重なるほど通りやすくなります。

```
みずで殴る   → 炎に有利(2.5) × 魔導士には等倍(1.0) = 2.5倍
けもので殴る　 → 炎に等倍(1.0) × 魔導士に有利(2.5) = 2.5倍
くさで殴る   → 炎に不利(0.6) × 魔導士には等倍(1.0) = 0.6倍
メタルで殴る → 炎に不利(0.6) × 魔導士にも不利(0.6) = 0.36倍
```

獄熱オニごん（炎＋魔導士）の場合：

| 味方の属性 | ボスへ与える | ボスから受ける |
|---|---|---|
| **みず・けもの** | **2.5倍** | **0.6倍** |
| む・ほのお・まじゅつし | 1.0倍 | 1.0倍 |
| くさ・パワー | 0.6倍 | 2.5倍 |

**みずかけものを連れていくのが正解**です。2.5倍を通しながら、受けるダメージは0.6倍で済みます。

## ふところの間合い（minRange）

```js
range: 300,        // ここまで届く
minRange: 130,     // これより近いと攻撃できない
```

味方が1体でも `minRange` の内側に入ると、その敵は**攻撃も前進もできなくなります**（獄熱オニごん）。
壁役を先に送り込んで懐にもぐりこむのが攻略法です。

## 章（ステージ）の構成

**各章7コース**（あき坊の塔だけ10階）。中ボスと大ボスは必ず入っています。

| 章 | 名前 | テーマ | 効きやすい味方の属性 | 大ボス |
|---|---|---|---|---|
| 1 | はじまりの のはら | 入門 | — | お菓子マン |
| 2 | はがねの まち | メタル混じり | みず・けもの | 獄熱オニごん |
| 3 | けものみち | 獣属性が多い | **パワー** | 森喰らい・ガオウ |
| 4 | 廃れたメカニック工場 | ほぼ全部メタル | **ほのお・まじゅつし・パワー** | 廃炉獣メルトギア |
| 5 | **賑わう近海** | ほぼ全部みず | **くさ**（フタバッポ・たたみん） | **波獣ザバーン** |

第5章の大ボス **波獣ザバーン** は体力36000（お菓子マンの4倍）、攻撃クールタイム0.5秒。
字一龍1体を連れて現れます。**たたみん**は水の攻撃を20%に抑え、
**フタバッポ**は水の攻撃を吸収して回復するので、この2体が最大の対策です。

章の名前と地図の位置は `CHAPTERS` で決まります。

```js
const CHAPTERS = {
  3: { name: 'けものみち', short: 'けもの', x: 0.51, y: 0.76, icon: '🐾' },
};
```

x / y は地図の左上を 0、右下を 1 とした割合です。第3章のまわりは自動で森が濃くなり、
第4章のまわりは工場と煙突が描かれます。

## 新しい特殊能力の書きかた（`js/data.js`）

```js
/* ぞくせい きゅうしゅう：きめた属性の攻撃はダメージ0。そのぶん回復する */
absorb: { attrs: ['water'], rate: 1.0 },   // rate 1.0 = ダメージと同じだけ回復
                                           // rate 0.5 なら半分だけ回復

/* クリティカル：かくりつで ダメージばいぞう */
crit: { chance: 0.15, mult: 3, ignoreAttr: true },
//     ↑15%       ↑3ばい  ↑true にすると属性の相性(2.5倍/0.6倍)を無視して
//                          「こうげきりょく × 3」きっかりのダメージになる
//                          false や 書かない ときは 相性のあとに かけ算

/* かくりつ ノックバック */
knockbackChance: 0.35,                     // 0.35 = 35%

/* こうげきりょくを さげる（たぬポン・クマった・メルトギア）*/
weaken: { chance: 0.30, rate: 0.6, duration: 3.0 },   // 30%で 攻撃力60%に 3秒

/* ピンチで 1度だけ 回復（コケジカ）*/
healOnce: { below: 0.5, rate: 0.3 },       // 体力50%以下で 最大体力の30%回復

/* ピンチで強くなる（ヌシノオオカミ・ガラク帝・ガオウ・メルトギア）*/
enrage: { below: 0.5, atkMult: 1.5 },      // 体力50%以下で攻撃力1.5倍
enrage: { below: 0.4, intervalMult: 0.6 }, // 体力40%以下で攻撃間隔0.6倍（＝速くなる）

/* ノックバック無効（ガオウ・ガラク帝・メルトギア）*/
kbImmune: true,

/* とくいな相手に追加ダメージ（モエリス）*/
bonusVs: { attrs: ['grass'], mult: 1.4 },  // 草の相手に さらに1.4倍

/* きめた属性のダメージを抑える（たたみん）*/
resist: { attrs: ['water'], mult: 0.2 },   // 水の攻撃を20%まで下げる
                                           // ふつうより小さくなるときだけ効きます
```

### コース単位で敵を強くする

```js
enemyMult: 1.25,                            // そのコースの敵ぜんぶを1.25倍
enemyBuff: { usagorilla: { hp: 3500 } },    // ウサ・ゴリラだけHPを3500に
```

`enemyBuff` は元の `ENEMIES` を書きかえません。そのコースに出るぶんだけ差しかわります。

## レア度と強さの傾斜

レア度が高いキャラほど**1体あたりの絶対的な強さ**が上がります。
ただし**コストと再生産時間も上がる**ので、「安く数を出す」のはノーマル・レアの役目です。

### 総合力の出しかた

```
総合力 ＝ √( 実質の毎秒ダメージ × 体力 )

実質の毎秒ダメージ ＝ 攻撃力 × 連撃数 ÷ (攻撃間隔 ＋ 振りかぶり) × 範囲ばいりつ
                     範囲ばいりつ … 範囲攻撃なら 1.6、単体なら 1.0
```

かけ算のルートを取っているので、**攻撃と体力の両方がある子ほど高く出ます**。
どちらかに偏った子は、合計が同じでも低く出ます。

**この数字に入っていないもの**（＝数字より実際は強い／弱いことがあります）

| 入っていないもの | 影響を受けるキャラ |
|---|---|
| コストと再生産時間 | 安いタンクンは数を出せるぶん、数字より強い |
| 射程 | スティーブ（射程1000）は数字より かなり強い |
| 特殊能力 | かべくん（攻撃0で50）、ぷりお（足止め）は数字より強い |

## キャラクター編成

**最大10体**まで連れていけます。トップ画面の「キャラクター へんせい」から。

1. 上の**わく（1〜10）をタップ**して選ぶ
2. 下の**キャラをタップ**すると、そのわくに入る
3. 同じわくをもう一度タップすると**はずせます**
4. **わくを長押し（0.3秒）するとつかんで動かせます。** 好きな場所で指をはなすと順番が入れかわります

並び順がそのまま**戦闘画面の下のボタンの並び**になります。
7体以上にすると自動で2段組（10体なら5列×2段）です。

## 属性の相性（じゃんけんが2つ）

```
【わ その1】 みず → ほのお → くさ → みず
【わ その2】 まじゅつし → パワー → けもの → まじゅつし
【メタル】   ほのお・まじゅつし・パワー の3つに弱い（得意な相手はなし）
【かみ】     どの属性にも 攻撃1.2倍／被ダメージ0.8倍。ただしメタルにだけは弱い
【ゆうれい】 相性はぜんぶ等倍。そのかわり「むぞくせい」と「パワー」の攻撃がきかない
```

### かみ属性（あき坊）

三すくみの外にいる特別な属性です。**すべての属性に少しだけ有利**ですが、
**メタルにだけは通常の弱点あつかい**（与える0.6倍／受ける2.5倍）になります。

| | かみが与える | かみが受ける |
|---|---|---|
| メタル以外 ぜんぶ | **1.2倍** | **0.8倍** |
| メタル | **0.6倍** | **2.5倍** |

倍率は `CONFIG.godAtk` / `CONFIG.godDef` で変えられます。

## ゆうれい属性（霊太郎）

相性は**すべて等倍**です。そのかわり **むぞくせい と パワー の攻撃をすりぬけます**（ダメージ0）。

```js
attr: 'ghost',
nullify: { attrs: ['none', 'power'] },
```

**大事なルール**：2つの属性を持つ敵（バーナー君＝メタル＋炎 など）の攻撃は**すりぬけできません**。
無効になるのは「その属性ひとつだけ」で殴ってくる相手だけです。

むぞくせいの敵はとても多い（トゲハヤさん・ブロック・ワン・ニョロリ〜ヌ・ほしくん・
ハコボット・ヤマネム・カモメェル）ので、**その並びに対しては無敵の壁**になります。

## 波動（あき坊）

にゃんこ大戦争と同じ考えかたです。**攻撃が当たったとき、前方へ波が走り、
通り道にいる敵ぜんぶに同じダメージ**を与えます。レベルが高いほど遠くまで届きます。

```js
wave: { level: 5, damageRate: 1.0 },   // レベル5・攻撃力と同じダメージ
```

届く距離は `CONFIG.wave.step` × レベル（今は 120 × 5 ＝ **600**）。
射程210と合わせると、**戦場のだいたい8割**に届きます。

- 有利なとき **2.5倍**（ダメージ数字が **赤** で大きく出ます）
- 不利なとき **0.6倍**（ダメージ数字が **グレー** で出ます）
- **2つの輪は別々**。輪をまたぐ組み合わせ（例：ほのお vs けもの）は等倍
- `む`（タンクン・ぷりおぷりねこ・ずにお）はどの属性とも相性なし
- `メタル` は**弱点が3つある代わりに基礎能力が高い**タイプ

倍率は `CONFIG.attrStrong` / `CONFIG.attrWeak`、相性そのものは `ATTR_BEATS` で変えられます。

## キャラの絵を差しかえたいとき

`js/draw.js` の中に、キャラ1体につき関数が1つあります（例：`drawHiibou`）。
中身を書きかえれば見た目が変わります。画像ファイルに差しかえる場合も、
この関数の中を `ctx.drawImage(...)` に置きかえるだけでOKです。

- 原点 `(0, 0)` はキャラの**足もとの中央**
- 上が **マイナス**、下が **プラス**
- 全員 **右向き**で描く（味方は自動で左右反転されます）

## 新しい版を公開する手順（作業する人むけ）

数値やキャラを変えたあと、ホーム画面のアプリにも反映させる手順です。

1. **バージョンを2か所そろえて上げる**（ここが要）
   - `js/main.js` の `GAME_VERSION`
   - `sw.js` の `APP_VERSION`

   > `sw.js` の中身が変わらないと、ブラウザが「新しい版が出た」と気づけません。
   > 数値だけ直して `sw.js` を触らないと、更新のおしらせが出ないので注意。

2. **GitHubに反映**
   ```bash
   git add -A
   git commit -m "v1.6 〇〇を調整"
   git push
   ```

3. 1〜2分でサイトが切りかわります。ゲームを開いている人の画面には
   **「✨ あたらしい バージョンが あります」**の帯が自動で出ます
   （開いているあいだ5分おきに確認しています）。

公開先: https://github.com/akihikoito-apps/gounosuke-game
