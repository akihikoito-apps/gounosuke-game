## 3. 隠れ場所 9か所（`spots`）と のぞき場所 3か所（`PEEKS`）

### 3.1 隠れ場所 9か所（`spots`）

すべてのスポットで以下の条件を満たすよう座標を設計しています：
- **画面内（`inBounds`）**：`76 <= x <= 924`, `220 <= y <= 989`（全キャラクターの輪郭がマージン6px以上内側）
- **重なりなし（`!spotsConflict`）**：同じ段のスポット同士は横方向に `160px` 以上離れ、奥の段（`y = 652`）と手前の段（`y = 884..956`）は縦方向に `232px` 以上離れているため、**9か所のうちどの3か所を同時に選んでも一切重なりません**。
- **顔が隠れない（`faceVisible`）**：顔の要点 `(-16, -142), (16, -142), (0, -125)` と小物の最上端との間に **27〜67px の安全余白** があります。
- **服の可視率（`bodyVisible`）と領域一致（`regionMatch`）**：服が約35〜45%見え（`0.20 <= bodyVisible <= 0.92`、かつ最難関の優先帯 `0.25..0.40` に入るスポットを含む）、見えている服の100%が対象 `region` の内部にあります（`regionMatch = 1.0`）。

### 7.2 新しい物 6つ（`ITEMS`）
