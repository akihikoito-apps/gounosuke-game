# 素材・コードの由来（ASSET_MANIFEST）

第三者のWeb画像、既存作品の画像・スクリーンショット、外部フォント、音声ファイルは **一切使っていません**。

| 素材 | 場所 | 由来 | AI支援 |
|---|---|---|---|
| キャラクター3体（ころ・みみ・もこ）の形・顔・色・性格 | `src/core/characters.ts` | 今回 SVG のコードとして新しく作成 | Claude（Claude Code）がコードを書いた |
| 背景3種（へや・にわ・おやつのみせ）、柄の領域、隠れ場所 | `src/core/scenes/*.ts` | 同上 | 同上 |
| 前景の小物（おもちゃ箱・植木鉢・クッション等16種） | `src/core/props.ts` | 同上 | 同上 |
| 服と背景の柄（無地・しま・水玉・チェック・葉・木目） | `src/core/patterns.ts` | SVG pattern をコードで生成 | 同上 |
| ボタンのアイコン | `src/ui/icons.ts` | 同上 | 同上 |
| アプリアイコン（SVG） | `public/icon.svg` | 同上 | 同上 |
| アプリアイコン（PNG 180/192/512） | `public/icon-*.png` | `scripts/make-icons.mjs` で上の SVG を Chromium で描画して作成 | 同上 |
| 効果音 | `src/audio/sound.ts` | 音声ファイルなし。Web Audio のサイン波を端末内で生成 | 同上 |
| 文字 | — | 端末の標準フォント（system-ui 等）。フォントの同梱なし | — |
| 画面写真・操作動画 | `screenshots/`, `video/` | このベータを Playwright で実際に操作して記録 | 同上 |

## 外部の画像生成について
外部の画像生成AIは使っていません（つながっておらず、別料金になる可能性もあったため）。すべての絵は上記のとおりコードで描いています。

## 似ていないかの確認
特定の作品に似せないよう、形（くるんとした毛／たれた長い耳／くもの形の頭と星の髪留め）と色を独自に決めました。既存作品との似ている度合いは人が見て判断する必要があり、権利の確認は済んでいません。

## 新しい背景を足すとき
背景レイヤー・柄の領域・隠れ場所・当たり判定を1つのファイルで定義 → `npm test` で全隠れ場所×全キャラクターを自動検査 → 画面写真で点検 → 本人承認、の順で行います。一枚絵に正解の座標を手で打つ方式にはしません。
