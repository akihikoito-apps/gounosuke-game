## レビュー指摘への対応（独立レビュー1回）

Claude のサブエージェントによる読み取り専用レビューの指摘（AGENT_STATUS.md）のうち、以下を修正し、回帰テストを追加しました。

- つづきから（隠すモード）→「かくしなおす」／「もういちど」で画面が止まる不具合 → 修正、回帰テスト追加
- 「おしまい」後にデータ削除しても、画面を離れた時に途中データが書き戻される → 修正、回帰テスト追加
- 保護者画面を開いている間に、後ろのゲーム画面へフォーカスが移る → 修正
- Service Worker がエラー応答をオフライン用ページとして保存しうる → 正常応答のみ保存に修正
- テスト用の読み取り窓口が本番ビルドに入っていた → 開発・e2e用ビルドだけに限定（unit `build` で確認）
- 空き場所タップのリスナーが cancel 時に残る／配置検証失敗時に何も起きない／キーボードで隠せない → 修正
- ゲートの連打耐性 → 3回失敗で3秒待ち、長押しを2.2秒に
