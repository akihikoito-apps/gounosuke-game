# 絵の差し替え口（ART_SLOTS）

`art/` フォルダに決まった名前でファイルを置くと、ゲームが自動でその絵を使います。
**置かなかった部分は、今のコードの絵のまま** 動きます（一部だけ差し替えてもよい）。

- 形式：PNG（透過）／WebP／SVG。1ファイル 800KB まで、合計 8MB まで
- SVG はスクリプト・外部参照・文字（フォント）を含めない
- 置いたら `npm run validate:art` で検査 → `npm run build` → 画面を確認
- 下書きガイド：`npm run art:guides` で `art-guides/` に出る（形状データから自動生成。描く位置の基準）

## キャラクター `art/characters/{koro|mimi|moko}/`

枠：**450×600px**（またはその整数倍。縦横比 3:4）。ゲーム内の座標 x −90〜90、y −225〜15 にあたり、**足もと中央（x 0, y 0）は画像の横中央・下から 37.5px**。ガイド `art-guides/character-*.png` に重ねて描く。

| ファイル | 必須 | 中身 |
|---|---|---|
| `clothes-mask.png` | ○ | 服の形だけを **白**、ほかは黒か透明。ここにゲームが背景と同じ柄を流し込む。ガイドの青い範囲（からだの判定）からはみ出さないこと |
| `front.png` | ○ | 服より前に描くもの：顔・頭・耳・髪・手・服の上に出る線。目と口はガイドの赤い点の位置 |
| `back.png` | | 服より後ろ：足、背中側の耳や髪など |
| `clothes-shade.png` | | 服の陰影（乗算で重なる）。グレー〜茶系の濃淡、透過 |
| `clothes-line.png` | | 服のふち線だけ。難易度に応じてゲームが濃さを変える（最低25%） |
| `front-found.png` | | 見つかった時の前面（手をふるポーズ）。無ければ front を使う |

`clothes-mask` と `front` がそろっていない時は、そのキャラクターはコードの絵のままです。

## シーン `art/scenes/{room|garden|shop}/`

枠：**1000×1000px**（2000×2000 推奨）。ガイド `art-guides/scene-*.png` の色面が「柄の領域」で、**ここはゲームが柄を塗る**（服と同じ柄にして隠れられるようにするため）。

| ファイル | 中身 | 決まり |
|---|---|---|
| `back.png` | 柄の領域より下：空・壁の上部・床など | 不透明でよい |
| `over.png` | 柄の領域の上・キャラクターの後ろ：家具の縁・カーテンのひだの陰・窓・棚など | 透過。キャラクターの服の後ろは薄く（平均の濃さ35%以下）、顔の後ろには描かない |
| `minor.png` | 小さい画面では省く飾り（壁の絵・雲など） | over と同じ決まり |
| `fore.png` | 前景の小物すべて（キャラクターの前に重なる） | 透過。ガイドの橙色の形に合わせる。**赤い円（顔）には重ねない**。服は少し（2割以上8割未満が見える程度）隠す |

## 柄のタイル `art/patterns/{シーン}-{服}.png`

例：`room-stripes.png`、`garden-leaf.png`。正方形 64px 以上、不透明、**上下左右がつなぎ目なく続く**こと。
同じタイルが背景の領域と服の両方に使われます（だから隠れられる）。タイル1枚がゲーム内で表す大きさは、各シーンの柄の `size`（38〜52）です。

| シーン | 服（ファイル名の後半） |
|---|---|
| room | plain（壁）, stripes（カーテン）, dots（ソファ）, check（ラグ） |
| garden | plain（芝生）, stripes（柵）, dots（花だん）, leaf（生け垣） |
| shop | plain（床）, stripes（カウンター）, dots（壁）, check（テーブルクロス） |

## 画面の絵 `art/ui/`

`title.png`（タイトルの絵）、`handoff.png`（受け渡し画面の絵。**隠れ場所や背景を描かない**）、`bye.png`（おしまい画面）。2000px 以内。
