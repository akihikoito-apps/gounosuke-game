# ジョブ16：森の ジャンボきのこ を ドーム形に合わせる（小さな直し）

## 書き込んでよい場所
`art/scenes/forest/` と `art/README.md` だけ

## 背景
ゲーム側で、きのこの傘（水玉の柄の領域 `mushroom`）を四角から **上が まるい ドーム形** に変えた（`src/core/scenes/forest.ts` の regions の mushroom。中心 x=775、下の端 y=654、左右 x=563〜987、いちばん上 y≈409 の半だ円）。
今の `back.svg`（または `over.svg`）に、前の四角に合わせた **クリーム色の角丸の四角**が傘の後ろに見えている（x 575〜965、y 400〜460 あたり）。これを消して、ドームに合う絵にしたい。

## やること
1. 傘の後ろのクリーム色の四角を消す（後ろは空と遠くの木々が見えるように）
2. `over.svg` に、ドームの ふち線（#4A3A40、ほかの背景と同じ太さ）と、傘の下の ひだ（下の端 y=640〜660 の白っぽい帯）、ドームの右上に うすい光、を足して、ジャンボきのこ に見えるようにする。**ドームの中（柄の上）を濃く塗りつぶさない**（友だちの服と同じ柄が見えないと隠れられないため。over の決まり：平均の濃さ35%以下、顔の位置には描かない）
3. `npm.cmd run validate:art` がすべて合格
