## 背景
追加パック第2弾「すいぞくかん（aquarium）」のプログラム実装に合わせて、対応する SVG 絵一式（**29枚**）を作る。

## 共通の決まり
- すべてベクター SVG（`<image>` 埋め込み禁止、`<text>` / `<foreignObject>` 禁止、外部 URL 禁止）
- 絵本のような温かい手描き風：やわらかい輪郭線（チャコール `#3A2E2A` またはディープネイビー `#1F3A52`、3〜5px、`stroke-linecap="round"`）＋やさしいグラデーションとハイライト
- 暗い深海ホラーや冷たいネオン調にはせず、昼間の明るいファミリー水族館（光のカーテンとパステルコーラル・ミント）にする
- 既存のキャラクター・作品のまねはしない

## 2. 新しい友だち `art/characters/puka/`（6枚）

**プカ（`puka`）**：うみの ぷかぷか（パステル水色のメンダコ／ウミウシの赤ちゃん）。
- **最重要ルール**：`art/characters/shio/` や `pino/` と **まったく同じ `viewBox="0 0 200 240"`・同じ服の輪郭** にする。特に `clothes-mask.svg` の外形（胴体の幅・高さ・位置）は既存キャラと揃えること。
- **頭の特徴（既存の6体と絶対にかぶらない形）**：
  - 頭頂はつるんと丸く（耳や角やトサカを上に生やさない）、**顔の左右のほっぺの横に、水平にパタパタ広がる小さな耳ヒレ（メンダコの耳びれ）** が1対ついている
  - 体の色はパステルシアン（`#BCEEFF`）、耳ヒレの先とほっぺはコーラルピンク（`#FF9EBB`）
  - 頭頂に小さな白い泡のリング（天使の輪ではなく、ぷかりと浮かぶ水泡2〜3個）を添えてもよい

| ファイル | 役割 |
|---|---|
| `clothes-mask.svg` | 服のシルエット（白 `#FFFFFF` 単色の塗り）。他キャラと同じ胴体サイズ |
| `front.svg` | 頭・顔（丸い目、にっこり口、左右の耳ヒレ）・手・足（服の上から重なる部分）。服の部分は透明にしておく |
| `back.svg` | 後ろ姿や体のベース（頭・手足の背面シルエット、パステルシアン `#BCEEFF`） |
| `clothes-shade.svg` | 服の上にかける立体感の影とハイライト（半透明の黒・白） |
| `clothes-line.svg` | 服の輪郭線と、胸元の小さな巻貝ポシェットや襟の線画（塗りつぶしなし、線のみ） |
| `front-found.svg` | 見つけたときの喜ぶ顔（目がキラキラ／にっこり万歳、両脇の耳ヒレがパタッと上がる） |

### 4.2 へやの背景 `art/myroom/rooms/aquarium-room.svg`（1枚）

## 絵のトーンについて（持ち主の希望）
持ち主は「パックごとに絵のトーンをそろえたい」と考えている。**先に描いた `art/scenes/forest/`・`art/characters/pino/`・`art/myroom/` の きのこの もり パック、および最初からの へや・にわ・おみせ・うみべ と並べて違和感がないこと**（線の色と太さ・くすみパステル・陰影の付け方・光の向き・顔の描き方）を最優先にする。
また、柄の領域はゲーム側で アーチ形などの形になっている（`src/core/scenes/aquarium.ts` の regions）。`back`/`over` は、その形に合わせて描き、四角い板の跡が残らないようにする（森で四角い跡が残った反省）。
