# ジョブ91：最難関コースの議論（第1回・提案）

## 書き込んでよい場所
`audit/codex/hardest-course-r1.md` の1ファイルだけ。**コード・絵・設定は変更しない**（読むのは自由）

## 背景
コースモード（10コース×10回）を作った。ご本人から「最難関コースを試しに遊びたい。どれほど難しくできるかは Codex とよく議論して作って」と依頼があった。
あなた（Codex）は、ゲームデザイナー兼レビュアーとして、**どこまで難しくできるか**を提案し、その危険も自分で指摘してほしい。Claude Code があなたの提案に反論・修正を返し、第2回で詰める。

## 読むもの
- `src/core/courses.ts`（コースの表。今のコース10が一番むずかしい）
- `src/core/accessories.ts`（ニット帽・傘。顔に重ねない・画面内・ほかの小物の下に入らない・camo は後ろの7割が同じ柄）
- `src/core/placement.ts`（LIMITS：全体の45%以上が見える、服は20〜92%見える、顔は必ず見える、高さ170以上 等）
- `src/core/session.ts`（当たり判定・3段階のヒント）、`src/core/patterns.ts`（soft/exact の柄）
- `src/ui/sceneView.ts`, `src/ui/accessoryArt.ts`, `src/ui/app.ts`（outline、表示）
- `OWNER_REVIEW.md`、`strategy/DIFFERENTIATION_DEBATE.md`（方針・やらないこと）
- 画面の様子：`screenshots/390x844_08-search-shop-normal.png` など

## 守る前提（ここは動かさない）
- 対象は4〜6歳と家族。外れても減点・時間切れ・怖い演出なし。ヒントは無料・無制限
- **顔（目と口）はどの難易度でも隠さない**（キャラクターが「いる」ことが分かる最低限の約束）
- 色覚に頼る見分けだけにしない。動くと見える型（アクション）にはしない
- 課金・広告・外部通信は入れない

## 考えてほしいこと
1. **難しくする手段の一覧**と、それぞれの効き目・副作用。例（これ以外もどんどん出して）：
   - 人数（3人まで → ？）、ふち線の濃さ（今の最小 0.32、下限 0.25）、服の柄（exact）
   - 帽子・傘の割合、帽子と傘を同時に、ほかの身につけ物（マフラー？ 手袋？ 背景の柄の箱をかぶる？）
   - 顔の見え方（顔は隠さないが、目以外を小さく／色を背景に寄せる？ → 前提との関係を必ず議論）
   - 隠れ場所（より小物に深く隠れる場所の追加、キャラクターを少し小さく）
   - 「にせもの」（顔のない同じ柄のかたまり）を置く、見つけた子の表示、ヒントの出方
   - 1回の出題の中の制限（例：みつける順番）
2. **最難関コースの具体案**：表の1行として（spots / variant / outline / maxChars / hat / umbrella / 新しい項目）。新しい項目が要るなら、何をどう作るか
3. 「むずかしい」と「ずるい・理不尽」の境目はどこか。4〜6歳と大人で分けて考える
4. 実装の手間（小・中・大）と、試遊で確かめるべきこと
5. あなたの案のうち、**自分でも危ないと思う点**（反論されそうな点）
