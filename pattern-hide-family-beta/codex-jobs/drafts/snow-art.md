   - `art/stickers/b-s1.svg`〜`b-s50.svg`、`art/stickers/f-s1.svg`〜`f-s50.svg`

## 背景
追加パック第3弾「ゆきの まち（snow）」のプログラム実装に合わせて、対応する SVG 絵一式（**27枚**）を作る（※うごくもののうち `cloud`・`bird`・`puppy` は既存絵をそのまま使うので、新規 mover は 2枚）。

## 共通の決まり
- すべてベクター SVG（`<image>` 埋め込み禁止、`<text>` / `<foreignObject>` 禁止、外部 URL 禁止）
- 絵本のような温かい手描き風：やわらかい輪郭線（ウォームチャコール `#3A2E2A`、3〜5px、`stroke-linecap="round"`）＋やさしいグラデーションとハイライト
- 寒々しい吹雪や暗い夜にはせず、**「晴れた冬の朝のパウダーブルー×ログハウスのオレンジ灯り×ベリーレッドのニット」** のぬくもりある絵本調にする
- 既存のキャラクター・作品のまねはしない

### 1.2 背景4層 `art/scenes/snow/`
- **`back.svg`**（遠景：y=0〜250 を中心に、下まで塗る）：
  - 晴れた冬の朝の淡いラベンダー〜ベビーブルーの空（`#DCEEF8` → `#F5FAFD`）

- **`fore.svg`**（手前の遮蔽物＝友だちの胴体下半分を隠す前景小物）：
  - `strategy/packs/snow-spec.md` §3.1 の 9か所の隠れ場所の足元（特に `y: 385〜700`）に、対応する柄・色の前景小物を配置する：
    1. 左のもみの木の雪枝（`(165, 420)` 付近、パイングリーンに白雪ドット）
    2. マフラーを巻いた雪だるま（`(195, 645)` 付近、赤×クリームしまの大きなマフラーと雪玉）
    3. かまくらの入り口ドーム（`(380, 520)` 付近、パウダーブルーの雪ブロック）
    4. チェック毛布の木製そり（`(510, 680)` 付近、オレンジ×ブラウンチェックの毛布）
    5. 中央もみの木の雪株（`(670, 405)` 付近、パイングリーンに白雪ドット）
    6. チェックのブランケットベンチ（`(765, 665)` 付近、オレンジ×ブラウンチェック）
    7. ロッジのしましまオーニングと煙突屋根（`(915, 385)` 付近、赤×クリームしま）

## 2. 新しい友だち `art/characters/kona/`（6枚）

**コナ（`kona`）**：ゆきの こな（ミルクココア色のこどものトナカイ）。
- **最重要ルール**：`art/characters/shio/` や `pino/` と **まったく同じ `viewBox="0 0 200 240"`・同じ服の輪郭** にする。特に `clothes-mask.svg` の外形（胴体の幅・高さ・位置）は既存キャラと揃えること。
- **頭の特徴（既存の6体＋プカと絶対にかぶらない形）**：
  - 頭の上に **先端がぷっくり丸いクリーム色（`#FFF6E5`）の小さな枝角（Y字に1回だけ枝分かれした丸い角）** が1対ついている。そのすぐ下に小さな横向きトナカイ耳
  - 体の毛色はあたたかいミルクココア色（`#C89D7C`）、顔の中央とおなかはクリーム色（`#FFF6E5`）
  - 鼻先は丸くてベリーレッド（`#E56B6F`）の小さな赤いお鼻、ほっぺはほんのりピンク

| ファイル | 役割 |
|---|---|
| `clothes-mask.svg` | 服のシルエット（白 `#FFFFFF` 単色の塗り）。他キャラと同じ胴体サイズ |
| `front.svg` | 頭・顔（丸い枝角、赤い丸鼻、にっこり口）・手・足（小さなひづめ風）。服の部分は透明にしておく |
| `back.svg` | 後ろ姿や体のベース（頭・角・手足の背面シルエット、ミルクココア色 `#C89D7C`） |
| `clothes-shade.svg` | 服の上にかける立体感の影とハイライト（半透明の黒・白） |
| `clothes-line.svg` | 服の輪郭線と、首元のふわもこボア襟や小さな鈴の線画（塗りつぶしなし、線のみ） |
| `front-found.svg` | 見つけたときの喜ぶ顔（目がキラキラ／にっこり万歳、角の周りに小さな雪のきらめき） |

## 4. じぶんの へや の絵 `art/myroom/`

### 4.1 へやの物 `art/myroom/items/{id}.svg`（6枚）
すべて `viewBox="0 0 160 160"`。`src/core/myroom.ts` の座席座標（`seats`）に合わせて、友だちが座れる形にする：

1. **`kotatsu.svg`**（ぽかぽか こたつ、`w: 210`、2人掛け `dx: -44, +44, dy: -4`）：
   - シナモンオレンジ×ブラウンのチェック柄こたつ布団に、木製の天板。天板の上にみかんが乗っている。左右から友だちが入って温まれる形。
2. **`rocking-chair.svg`**（ゆりいす、`w: 140`、1人掛け `dx: 0, dy: -12`）：
   - あたたかい木目のロッキングチェアに、ベリーレッド×クリームしま模様のニットクッションが敷いてある。
3. **`snowman.svg`**（ミニ ゆきだるま、`w: 96`）：
   - 溶けない魔法の小さな二段雪だるま。赤いバケツ帽子としましまマフラー、にっこり顔。
4. **`snow-globe.svg`**（スノードーム、`w: 92`）：
   - 木の台座に乗った丸いガラスのスノードーム。中に小さな赤い屋根のロッジともみの木、白い粉雪が舞っている。
5. **`stew-pot.svg`**（シチューの おなべ、`w: 110`）：
   - ベリーレッドのホーロー両手鍋。ふたが少し開いて、あたたかいクリームシチューの湯気がぽわんと出ている。
6. **`snow-bunny.svg`**（ゆきうさぎ、`w: 88`）：
   - 小さな木の盆（または赤いフェルト敷き）の上に乗った、葉っぱの耳と赤い目のまんまる雪うさぎ。

### 4.2 へやの背景 `art/myroom/rooms/loghouse.svg`（1枚）
- `viewBox="0 0 1280 800"`、床の上端は **`y = 560`**（`floorTop: 560`）。
- **`y: 0..560`（壁）**：丸太組みのあたたかい壁（ハニーブラウン `#C88A56`）の「ログハウス」。奥にレンガ造りの暖炉（安全柵つき、オレンジ色のやさしい炎）、窓の外には雪景色ともみの木が見える。壁にニットの靴下や星型の木製オーナメント。
- **`y: 560..800`（床）**：明るいパイン材のフローリング床と、クリーム色のラグの縁。家具や友だちを置いても見やすい落ち着いた明度にする。
