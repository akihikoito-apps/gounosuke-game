# ジョブ09：シールちょうのシール15枚

## 書き込んでよい場所
`art/stickers/` と `art/README.md` だけ

## 読むもの
AGENTS.md / ART_SLOTS.md の「シール」/ CODEX_ART_BRIEF.md の「絵の方向性」/ `src/core/stickers.ts`（15枚の id・名前・キャラクター・モチーフ・地の色。変更はしない）/ art/characters/（キャラクターの画風）

## やること
- 15枚：c1〜c10、f10、f30、f60、f100、f150。それぞれ stickers.ts の char（キャラクター）と motif（ボール・クッション・くも・はな・プレゼント・ケーキ・おつきさま・さかな・にじ・おうかん・はっぱ・パン・ハート・ふうせん・ほし）と color（地の色）で
- 白いふちの丸いシール。キャラクターは顔か上半身で、モチーフと楽しそうに。f系（回数）は少し特別感（きらきら・ふちを金色っぽく など、控えめに）
- 480×480px、透過PNG または SVG。文字は入れない
- 集めたくなる、かわいくて品のある絵本の挿絵の画風。安っぽいきらきらにはしない

## 合格条件
- `npm.cmd run validate:art` がすべて合格
