# ジョブ98：App Store に出す文言・画像のダブルチェック（審査に出す前）

## 書き込んでよい場所
`audit/codex/review-store-listing.md` の1ファイルだけ。コード・絵・文書・設定は変更しない（読むのは自由。読むだけのコマンドは可。ネット接続・公開・push はしない）

## 背景
「もようのかくれんぼ」（3〜6歳と親向け、Apple の Kids カテゴリ 5歳以下）を App Store の審査に出す直前。持ち主は「登録する文言や画像は、ダブルチェック・トリプルチェックしてほしい」と言っている。Antigravity（Gemini）にも別に同じ点検を頼んでいる。あなたは独立して点検する。

## 読むもの
- 文言：`strategy/APP_STORE.md`（§2 名前・サブタイトル・プロモーション用テキスト・説明・キーワード・URL・著作権、§3 年齢制限、§4 プライバシー、§6 審査メモ、§7 輸出）。説明は App Store Connect にこの内容で入力済み
- 追加パック（アプリ内課金）7つ：`native/IAP_SETUP.md`（表示名・説明・値段）と `src/purchase/store.ts`（アプリ内の説明）
- 画面写真：`native/store-shots/framed/iphone69-*.png`（6枚）と `native/store-shots/framed/ipad13-*.png`（6枚）、課金の審査用 `native/store-shots/iap-review.png`。画像を開いて見ること
- 中身との照合：`src/core/scenes/`、`src/core/characters.ts`、`src/core/myroom.ts`、`src/core/stickers.ts`、`src/entitlements/entitlements.ts`
- 公開ページ：`site/privacy.html`、`site/support.html`

## 点検すること（重要な順）
1. **審査で落ちる・差し戻される恐れ**：Kids カテゴリの決まり（保護者ゲート、外部リンク、広告、データ収集、購入の案内）、ガイドライン 2.3（説明と中身の一致）、3.1（課金の説明）、画面写真が実際のアプリと違う所、文字数の上限（名前・サブタイトル30、プロモーション170、説明4000、キーワード100、課金の表示名30・説明55）、他社の名前・商標・「No.1」などの言い過ぎ
2. **説明と中身の食い違い**：数（背景・友だち・へや・おもちゃ・シール・コース）、無料で遊べる範囲、パックの中身。コードを数えて照合する
3. **画面写真**：見出しの文字の誤り・読みやすさ、無料の写真に有料の物が写っていないか（6枚目以外）、iPhone と iPad で同じ内容か、文字の切れ・はみ出し
4. **ことば**：誤字・脱字、表記ゆれ（「家具」「おもちゃ」、ひらがな/漢字、全角/半角）、親に伝わるか、子ども向けとして不適切な言葉
5. **キーワード**：重複・名前と同じ語の無駄、もっと検索されそうな語の提案（100文字以内で書き直し案）
6. 年齢制限・プライバシーの答えが中身と合っているか

## 書き方
`audit/codex/review-store-listing.md` に。①審査で止まる恐れ（必ず直す）→ ②直したほうがよい → ③好みの範囲、の順。それぞれ「どこ（ファイル名・画像名・項目名）」「何がだめか」「直した文言（そのまま貼れる形）」を書く。推測は推測と書く。最後に、修正後の説明文・キーワード・プロモーション用テキストの完成版を貼る（直す所がなければ「このままでよい」と書く）
