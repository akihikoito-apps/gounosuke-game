# ジョブ13：アプリのアイコンと起動画面

## 書き込んでよい場所
`art/app/` と `art/README.md` だけ

## 読むもの
AGENTS.md / CODEX_ART_BRIEF.md の「絵の方向性」/ art/characters/（キャラクターの画風）/ art/ui/title.png（タイトルの絵）/ art/patterns/（柄タイル）

## 背景
App Store に出す iPhone アプリのアイコンと、起動したときに一瞬出る画面。ストアで最初に目に入る、いちばん大事な絵。
「柄にまぎれて かくれんぼ」が一目で伝わり、幼い子と親が「かわいい、品がいい」と感じること。

## やること
1. `art/app/icon.svg`（1024×1024）
   - **透明な部分を作らない**（四隅まで塗る。角の丸みは iPhone が自動でつけるので、四角いまま描く）
   - 例：柄（しま・水玉・チェックのどれか）の布から、ころ（またはころ＋1体）が顔を半分のぞかせている。柄が服に溶け込んでいる様子が分かる
   - 小さく表示しても（60×60）顔と柄が分かる太い形。**文字は入れない**
   - 既存の有名なアプリのアイコンに似せない
2. `art/app/splash.svg`（2732×2732、透明なし）
   - 地の色 #FFF6E8（ゲームの背景色）。中央の 1200×1200 の範囲に、タイトルの絵（3体がのぞく絵）に近い絵。**文字は入れない**
   - 画面の大きさで上下左右が切り取られるので、大事なものは中央に

## 合格条件
- 2枚とも SVG、外部参照・文字・スクリプトなし
- `npm.cmd run validate:art` がすべて合格（art/app は形式・安全性だけ検査される）
