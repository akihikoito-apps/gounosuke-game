# スマホ・タブレットで開く方法

作成日：2026-10-06

## 現状：スマホから開けるURLはまだありません

- このベータは **Anthropic のクラウド上の一時的な作業環境**（Claude Code のクラウドセッション）で作りました。ご自宅のPCではありません。
- そのため `http://127.0.0.1:4173/` などのURLは、**この作業環境の中からしか開けません**。スマホやご自宅のPCからは開けません。
- 新しい公開URL・公開トンネル・Firewall例外・外向きポートは作っていません（指示どおり）。
- この作業環境は一定時間で消えます。成果を残すには、GitHub への push か、ご自宅PCへの取り込みが必要です（下の「承認が必要なこと」）。

## 実際に使える経路の候補（どれも未実施・要承認）

### 案A：ご自宅PCで動かし、同じPCのブラウザで見る（いちばん安全）

1. この作業ブランチ `claude/pattern-hide-family-beta` を GitHub に push する（要承認）
2. ご自宅PCで取り込み、`pattern-hide-family-beta` フォルダで `npm ci` → `npm run build` → `npm run preview`
3. ご自宅PCのブラウザで `http://127.0.0.1:4173/` を開く
   - Chrome の開発者ツールの「デバイスモード」でスマホ表示を確認できます（実機の確認にはなりません）

### 案B：ご自宅のWi-Fi内のスマホから開く

案Aに加えて、ご自宅PCで `npx vite preview --host 0.0.0.0 --port 4173` のように **LAN へ公開** する必要があります。

- PCのFirewallで受信を許可する必要が出ることがあります（OS設定の変更＝今回は禁止事項なので、ご本人の判断が必要）
- 同じWi-Fi内の他の機器からも見えます
- `http://` の LAN アクセスは「安全なコンテキスト」ではないため、**Service Worker が動かず、通信OFFでの再起動はできません**。開いたままなら通信OFFでも遊べます
- 開くURLは `http://（ご自宅PCのLAN内IPアドレス）:4173/` です。IPアドレスはこちらでは分からないため、ここには書きません

### 案C：claude.ai の非公開アーティファクトとして載せる

ビルド済みのページを、ご本人のアカウントでだけ見られる **非公開** ページとして claude.ai に載せる方法です。スマホの Claude アプリ／ブラウザ（ログイン済み）で開けます。

- 一般公開ではありませんが、ご本人が共有操作をすれば他の人にも見せられます
- 今回の指示（Webへの公開をしない・既に許可された認証付きプレビューだけ使う）との関係が判断の分かれ目なので、**実施していません**
- 中の動き（保存・オフライン）はアーティファクトの表示環境の制限を受けます（未確認）

## してはいけないこと（指示どおり守っています）

- 既存の GitHub Pages（このリポジトリの main ブランチ＝別のゲームの公開先）に混ぜて公開しない
  - **main へ入れると、そのまま一般公開される可能性があります。** このベータは main に入れていません
- 推測のURLをスマホ用リンクとして書かない

## 2026-10-08：案C を実施（本人承認済み）
- ご本人の選択により、ビルド済みのゲーム（`dist/` から Service Worker・マニフェストを除いたもの）を claude.ai の **非公開アーティファクト** として載せた
- 見られるのはご本人のアカウントだけ（共有操作をしない限り）。一般公開・GitHub Pages・main ブランチは使っていない
- 表示環境の制限：Service Worker は動かないため、通信OFFでの再起動はできない。保存はその端末のブラウザの中だけ
- 絵やコードを更新したら、Claude Code が `npm run build` から作り直して同じURLに再掲載する
